## The idea

arXiv:2610.18174 (Research 623) proves a slow oscillatory Jacobian mode rate-limits coupled convergence (Theorem 3.2: complement settling time inherits `r`, the mode modulus; `τ_δ ≈ log(1/δ)/(−log r)`; `r = 1` ⇒ bounded, never converges), and shows raw-residual halting mistakes symmetry motion for unfinished computation while its quotient residual halts 4.5× earlier. Every one of those convergence laws is usable WITHOUT training: the mode `(r, ω)` is recoverable from the delta sequence of ANY iterative loop by a closed-form 2nd-order fit. The workspace's halting/classification stack consumes direction-only signals today; this issue adds the modulus channel, the budget law, the certificate, and — for phase-carrying state — the write-residual (free-dynamics innovation) commit law. **Guard (verdict round 1): no quotient residual (`r_G`) may ever be wired into `forward_looped`/`GainCostLoopHalter` — that state is not equivariant, and the paper's FPRM+momentum ablation (77.0 acc, 23% false halts) is exactly the bolt-a-quotient-onto-a-non-equivariant-loop failure class. P1–P3 use no quotient and are unaffected.**

## Why not already covered (signal-diff vs shipped cousins)

- **`GainCostLoopHalter` (`HaltReason::Oscillation`):** consumes cos_theta direction reversal + patience. No rate channel — cannot separate flip-with-`r<1` (converging THROUGH the oscillation; arXiv:2610.18174 App. A.4.4 measured that killing this DEGRADES the computation) from flip-with-`r≈1` (limit cycle).
- **`bench_011`/`bench_013` trajectory classifier:** curvature + length heuristics over labeled archetypes. No spectral attribution: "stuck" vs "orbiting" is `B≈0` vs `B≠0` at `r≈1` — needs the mode fit.
- **Research 620 / issue 939 (`phase_belief`):** owns the oscillation/capacity axis (propagation operator regimes) and the phase-carrying block itself — but ships no convergence criterion; P2's fade-together smoke documents the exact ambiguity (phase meaning outlives magnitude) that P4's innovation residual resolves. Note: the paper's gauge-quotient `r_G` does NOT apply on this substrate (single-complex-scalar orbits collapse it to the magnitude residual); the fix is the free-dynamics innovation residual.
- **Issue 717 (damping knobs):** arms damping; QRR supplies the trigger (two-signal: `r≈1` AND complement stagnation), the causal test (α-intervention), and the tension law (never damp a settling oscillation).
- **`fit_cv_least_squares` (katgpt-attn-match):** attention value reconstruction — different object; no delta-sequence recurrence fit ships anywhere.

- [ ] P4. **Write-residual commit law for `phase_belief`** (DEFER-UNTIL-PULL, aligned with Issue 939; verdict rounds 1–2). The paper's gauge-quotient `r_G` is WRONG here: each `phase_belief` channel is a single complex scalar (`[f32; 2]`, θ FIXED at `new(rho, theta)`), and for single-scalar orbits `inf_φ‖w − e^{iφ}z‖ = |‖w‖ − ‖z‖|` EXACTLY — the residual collapses to magnitude-only, destroying the phase content the substrate exists to carry. The sound commit law measures writes against the KNOWN FREE DYNAMICS: `step` computes `z_{t+1} = ρR(θ)z_t + u_t` exactly, so the free-dynamics innovation IS the write — `r_free = ‖u_t‖ / (‖z_t‖ + ε)`, a normalized write magnitude computed DIRECTLY from the caller's write `u`, never reconstructed from `z` (mul_add rounding leaves ULP residue that would break the exact-zero arm). `ρ`, `cosθ`, `sinθ` are construction parameters — zero training. **Commit when `r_free` stays below a calibrated threshold for a persistence window W.** Semantic honesty: `r_free` is a normalized write magnitude — "sustained identical writes ⇒ committed" is a DESIGN DECISION the consumer pull ratifies, not an emergent property (see the constant-write boundary below). Gate: ε and W in the spec; **write-stop fixture** — phase keeps rotating after the write ceases; `r_free` drops to exactly 0 at the write-stop step ± W while the RELATIVE raw residual `‖Δz‖/‖z_t‖ = |ρe^{iθ}−1|` (= `budget_scale`, already computed in `new`) stays constant — the gate compares the RELATIVE raw residual (normalized by `‖z_t‖`), never an absolute one (absolute `‖Δz‖ = ρⁿ‖(ρR−I)z₀‖` decays under any fixed threshold and fires spuriously); **exact identity arm** — a pure free-orbit run (u = 0) gives `r_free = 0` bit-exactly. Documented boundary (prose, not a gate arm): under constant write `u` with ρ<1 the state converges to `z* = (I−ρR)⁻¹u` — raw Δz → 0 reads "settled" while `r_free` stays `‖u‖/‖z*‖ > 0` reads "still writing" — which signal wins is the consumer's call at pull time.
