## Problem

The KV-quant family is GOAT'd on PPL + task suites (KVarN Bench 053 ran AIME24/MATH500/HumanEval/IFEval), but has **no diagnostic** for the failure mode the lossy gate's external validation #4 shows dominates at low bits: behavioral subspaces 10²–10³× more quantization-fragile than the PPL-averaged space. Today, if a backend fails a family-conditional retention read, the only path forward is brute-force bit-width sweeps — no answer to *which channels/layers carry the damage* or *which mitigation direction* (finer granularity vs precision floor vs allocation spread). The paper's PCR diagnostic predicts the correct mitigation from ~20 calibration prompts, training-free.

Metrics are pre-softmax (sigmoid-not-softmax law): damage = 1 − mean top-k attention-target overlap (first-index ties; the streaming top-k displaces the largest index among tied minima so the surviving set matches the stable-sort selection exactly), companions = relative distortion + k=1 pick-flip rate; V side = relative context distortion under caller weights (`None` = uniform). ## Acceptance (GOAT)

- [ ] **G1 correctness (instrument, not gain):** probe deterministic (fixed prompt set + fixed seeds); classification stable across prompt resamples within the disclosed band. A T3 negative result must be readable as a finding about the models, never as the instrument being broken.
- **G2 perf/memory (the gain claim, both controls):** the behavioral-damage weighting recovers retention at lower average bits than BOTH (1) uniform allocation and (2) the shipped structural-rank weighting — or matches both at equal bits with a strictly better retention profile; `--release` mandatory.
- **G3 no regression:** lossless path bit-identical; feature-off byte-identical boots.
- **G4 alloc:** allocation LOOKUP on the decode path is zero-alloc in the steady state. The ~20-prompt probe itself is a CALIBRATION step (one-shot, like `sst_certified`'s f64 Gram fit) — it is not held to the steady-state standard.
- **Report-the-floor:** retention numbers quote BOTH floors beside them — uniform-at-equal-bits AND structural-rank-at-equal-bits — a comparison against f16 alone hides the ordering claim this issue makes.
