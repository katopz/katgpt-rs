## Goal

Four gradient-free instruments that measure/localize reward-relevant signal in labeled (state, outcome) captures. None claims novel math — each is textbook statistics composed into a census kit with typed verdicts and loud refusals, and TWO OF THE FOUR reuse shipped code (I2 the shared log-gamma kernel, I4 the shipped mean-difference constructor). Determinism: blake3-reproducible, fixed tie rules (first-index), G4 alloc-free on the hot paths.

## Instruments

- [x] **I1 — `td_delta` estimator + MC significance gate.** API carries the GENERAL Bellman form δt = r_t + γ·V̂(t) − V̂(t−1) (per-step reward first-class); the paper's sparse-terminal-reward shape (r_t = 0 for t < T, terminal δ = r − V̂(T)) is the DEFAULT instance, so a consumer with per-step rewards cannot get a silently wrong δ. Significance gate `|δ| > z_α·σ̂/√K` with the K-budget inverse `K = ⌈(z_α·σ̂/δ_min)²⌉`. Fixture: hand-computed trajectory with a known V table → deltas bit-exact (both the terminal-reward instance and one per-step-reward case); synthetic Gaussian-δ coverage at nominal α within band. Falsifiers: shuffled state order must shift deltas per the identity (wrong order ≠ same output); K=1 with mis-set σ̂ measurably inflates FP (the gate must catch it). **LANDED** — `td_delta`/`td_significance`/`k_budget` + the `RewardSpec` enum (SparseTerminal the default; PerStep typed-required), 3 fixtures + the identity falsifier green.
- [x] **I2 — hypergeometric set-overlap null.** `P(overlap ≥ x | two random k-of-N sets)` + `E[IoU]` — the paper's Appendix C baseline, made a p-value. **Reuse the shared Lanczos log-gamma kernel** (`crate::special_fn::ln_gamma`, Plan 597 T1.1 — the kernel `best_belief.rs`'s ln B(a,b) and `bmr.rs` already consume); NO new log-space combinatorics. ⚠ Implementer note (from the verdict review): `special_fn` is `pub(crate)` and the comment at `katgpt-core/src/lib.rs:1715` says it is limited to its consumers — but the reviewer found no `#[cfg]` gating the module, so comment and code disagree; check what actually controls the module when this lands (if gated, add the `diagnostics` member to the gate) and run `cargo clippy --no-default-features` so any dead-code warning surfaces at implementation time, not after merge. Fixture: small-N exhaustive enumeration cross-check, max abs err < 1e-12. Falsifier: N=0 / k>N typed refusals; asymptotic-vs-exact sanity arm. **LANDED** — the note RESOLVED: `special_fn` is ungated `pub(crate)` (comment overstated; no gate change needed, verified `--no-default-features` clippy-clean), consumed as-is. f64 p-value (f32 would quantize the 1e-3..1e-12 tail), exhaustive 8-choose-3×4 fixture < 1e-12, monotone-in-x + typed refusals green.
- [x] **I3 — L1 pruning-curve knee census.** Keep-fraction sweep zeroing coordinates by |w| on ANY weight vector, metric-vs-keep-fraction curve + knee detection with a TYPED `NoKnee` verdict (never invents a knee). **First read the existing elbow logic** in `katgpt-core/src/log_frontier.rs` and `subspace_phase_gate.rs` — reuse/extend whichever detector fits; a THIRD parallel knee implementation is a DRY violation, not a kit member.
