# Issue 956: Binary-diffusion modelless extraction — lattice reopening + Ψ-sampler knobs

**Status:** Open — modelless track of the riir-train Research 480 verdict (private repo; training track = riir-train Issue 641). Source: arXiv:2610.28543 (candidate-set binary diffusion). All work behind `lattice_deduction` / opt-in flags; G3 byte-identity at every knob's zero.

Evidence law being consumed: restore-capable candidate evolution beats prune-only on hard instances (paper Table 1: bin-sym 92.7 vs masked 76.1 hard-Sudoku; hard graphs 64.1 vs 4.9). Our shipped lattice is prune-only per pass with whole-node DDTree backtracking; our d2f remask loop is threshold-based. Honest mechanism-class note: β-priority reopen ≈ CDCL phase saving (restore last value on unassign — standard since MiniSat); the delta here is belief-ranked, budget-preserving reopening over learned candidate sets inside a neural-guided lattice search. Directional only until the bench confirms — the paper's denoisers are trained, ours are modelless.

## Tasks

- [ ] **T1 (hardness-stratified bench reporting — P0, bench-only, precondition for everything below).** `tests/bench_ldt_lattice_deduction.rs` gains easy/hard strata (per-instance difficulty bins fixed on validation, mean + stratum both reported, matched budgets × seeds). The paper's central law is stratum-conditional; a pooled-mean bench is structurally blind to the effect we are buying. No production code changes.
- [ ] **T2 (conflict-triggered targeted candidate reopening in the α-lattice — P1, the fusion).** Design: `alpha_intersect` stays MONOTONE per pass (never break the propagator law); add an elimination-time memory (score at elimination — `LdtPruneConfig::theta_elim` ≈ 0.111 already implies the score exists); on `EntropyConflictDetector::is_conflicted` fire, reopen the top-b eliminated candidates at **ConflictClauseDB-implicated positions**, ranked `score^β`; re-propagate; bound by T2b. Gate (existing bench + T1 strata): G1 solve rate stratified easy/hard (hard stratum is the deciding read); G3 byte-identity when no conflict ever fires (that IS the default-off path); G2 wall ≤ +10%; G4 alloc-free reopen pass. Termination gate (reopening breaks the monotonicity Plans 088/170 relied on for termination): (i) **no-cycle invariant** — never reopen a candidate a LIVE conflict clause excludes; (ii) a **per-node reopen cap**; (iii) a **progress test** asserting search makes progress with no prune/reopen oscillation on the hard stratum (the FSM no-unbounded-back-and-forth law applied to solver state). CDCL gets progress from learned clauses — the clause DB must carry the same weight here.

This is distinct from `build_dd_tree_screened`: node backtracking is coarse time-travel under a prune-only kernel; the paper's ablation isolates per-position revisability as the active ingredient (+10.5 pts from re-corruption alone before any confidence guidance). CDCL synthesis for free: the clause DB already learns WHERE the conflict was; β decides WHICH candidate to restore there.
- [ ] **T2b (expected-reopen-count preservation — the anti-thrash budget, rides T2).** b from capped-mean bisection over elimination scores so expected reopens = η (one scalar solve per pass; σ-form `σ(γ·(τ − score))`, never softmax); pin a reopen-cycles-per-solve counter in the G1 record; the hard-stratum delta must clear the thrash cost. Prevents the reopen/re-eliminate oscillation — the FSM law (stalemates are drives, not counters) applied to solver state.
- [ ] **T3 (Ψ-κ/λ knobs on the d2f remask loop — P2, opt-in).** `katgpt-forward/src/d2f/`: (a) κ — confidence-budgeted re-corruption: κ_i ∝ σ(γ·(τ − conf_i)) with capped-mean-preserving bisection so mean κ = η, replacing/augmenting the fixed threshold (paper ladder: masked Sudoku hard ancestral 50.75 → re-corrupt 64.39 → +position-conf 76.56); (b) λ — per-position remask DEPTH tilt (less-confident positions return to deeper noise; mean-preserving by the same bisection); (c) expose (γ, λ, β) as new config dimensions in `StateActionCache` inference-configs (UnMaskFork already prices remasking strategies per mask ratio). Gate: G3 byte-identity at γ=λ=0; equal-N G1 delta on existing d2f fixtures, or the promotion form: equal accuracy at fewer steps (G2). Consumer caveat: the D2F text-output lane is research-scale (riir-infer Research 008 precedent) — opt-in only, no promotion path without a consumer.
- [ ] **T4 (flip-move pricing probe — probe-first, no GOAT without it).** O(V) single-flip pricing: all V single-token alternatives priced from the already-computed μ via kernel ratios (closed-form, zero extra forwards). Probe: flip-move vs resample-move win rate on OUR distribution shape before any gate — honestly speculative.
