## Problem

Memory Attention (arXiv:2609.28399) shows `V = K + Norm(E_l[s])` is a *sufficient* value pathway when trained from scratch (better PPL, NIAH 97.4 vs 82.6, 1.42× token efficiency). Research 165 showed K/V redundancy (cosine 0.73) — `V := K` costs only 2.5–3.1% PPL and halves the V cache; Gemma-4 ships the trained variant (`attention_k_eq_v`, our riir-infer loader already falls back V=K). **What ships nowhere: fitting the dropped residual per token** — the per-(layer, token) mean of `V − K` is a closed-form estimator on a frozen checkpoint, and it converts "K=V sharing with a known quality tax" into "K=V+ with the tax partially refunded", plus a variance-bounded cache-quant decomposition (variance cannot increase; the quantizer-level gain is measured, not proven — P1), plus V-cache halving by reconstruction. Same estimator family as Issue 882's Q-side anchors (`q̂ = q − λ·ā`): here `v̂ = k + λ·ē_l[s]`.

## The primitive

One calibration pass over ~10⁸–10⁹ tokens (WikiText/FineWeb slice) through a frozen checkpoint with V/K taps at every layer yields, streaming and closed-form:
- `E_l[s] = mean(V_t − K_t | s_t=s)` (pre-RoPE K tap) — the retrofit table, shrunk `E_λ[s] = n_s/(n_s+λ)·mean_s` (James-Stein tail control; λ by direct evaluation on held-out fixtures, the 882 discipline, never GD);
- `E^V_l[s] = mean(V_t | s_t=s)` — the value-mean table for the quant decomposition;
- the **R² dashboard**: per-layer per-head token-explained fractions ρ_l(V), ρ_l(V−K) from accumulated sufficient statistics (law of total variance) — the offline go/no-go for every task below;
- Zipf coverage curves for top-K table residency.

Every product's expected gain is a monotone function of ρ_l, computable before any serving change. Tables are `EngramTableId`-committable, `ZipfianCacheHierarchy`-resident (top-K dial), `EngramHotSwap`-swappable — the Plan 408 deterministically-constructed-values legality class.

## Known traps (panel-derived, load-bearing)

1. **Tap-point consistency** — the fit must tap K exactly where the cache/projection stores it (pre-RoPE; post-QK-norm for gemma-3/4-class — gemma-2 has none). A mismatched tap is silent corruption.
2. **Never round-trip rotations** — single one-directional rotate per read; f32 error compounds otherwise.
3. **Sinks are legitimate outliers** (882 trap 3, same here) — the per-token table ABSORBS sink means rather than exempting them; verify sink behavior doesn't regress at P1 via the shipped `kv_sink_window` machinery.
4. **ρ_l ≈ 0 is a valid answer — on a mechanism-bearing fixture only** — if token identity explains little of V−K on a GQA/MHA checkpoint with a real K/V split (e.g. gemma-2-2b), K=V was already right for that checkpoint; a null on a KDA/MLA fixture is FIXTURE-class (the architecture lacks the mechanism), never model-class (P0). The dashboard exists to say so before anything is built.
5. **λ by direct evaluation, never GD** — grid on held-out fixtures, per-layer schedule allowed; λ=0 must be bit-identical.
6. **Quality claims need the retention walk** — lossy surfaces gate per-family conditional retention, never aggregate-only (the riir-ai Issue-750-T3 / Orthrus law).
7. **Box state on every perf figure** — the G2 law: free RAM, commit-vs-limit, concurrent jobs, power state on laptops.
