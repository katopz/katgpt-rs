## Arm B — cross-layer KV-sharing init: closed-form loss-delta measurement

YASA's appendix recipe as a load-time weight transform: keys via `katgpt_spectral::procrustes` (alternate per-member rotations + average, logit-invariant), values via Eckart–Young rank-n over stacked `O_m·V_m` products, `C_m` absorbed into output matrices, rank-one reference correction. YASA measured (post-init, pre-CPT): naive copy +2.31 bits/byte → aligned 1.15 → +correction 0.62.

### T5 pre-registration (PINNED 2026-11-28, zed-7bab0f17@amo, BEFORE any cell — the calibration-gate law)

**Checkpoint:** `../riir-train/data/Ternary-Bonsai-2.5-27B-PQ2_0.gguf` (the LEAGUE model; sha256 pinned in `riir-train/data/BASE_MODELS.md`/`BACKUP_MANIFEST.tsv`). Header facts verified by direct GGUF-header read 2026-11-28 (amo): `qwen35` arch, 64 blocks, d_model 5120, **24 q heads (gated packing `[q(hd), gate(hd)]` per head, Issue 594) × 256**, **4 kv heads × 256** (GQA 6 q-heads/kv-head), `attn_q_norm`/`attn_k_norm` = [256] per-head-dim gains (shared across heads), `rope.freq_base = 1e7`, **`rope.dimension_count = 64`** (partial RoPE, rotate-half pairs `(i, i+32)`, dims 64..256 unrotated), `full_attention_interval = 4`.

**The layer pair:** FA layers are {3, 7, 11, …, 63} — every 4th block. NO two FA layers are adjacent (the hybrid interleaves three DeltaNet layers between every FA pair); the pair is **(3, 7)** — the closest-gap convention (gap 4, disclosed as a CONFOUND: the consumer's input distribution is 3 DeltaNet layers downstream of the producer's output, unlike YASA's adjacent dense pair; a null here must NOT be read as refuting the recipe on adjacent pairs). Producer = 3, consumer = 7.

**The three arms** (all over the same loaded checkpoint, deltas isolate the sharing): 
1. **baseline (unshared)** — the checkpoint as-is; layer 7 computes its own K/V.
2. **naive copy** — layer 7's attention reads layer 3's K/V cache verbatim (its queries unchanged, its output projection unchanged; its own W_k/W_v skipped).
3. **aligned init** — layer 7 reads layer 3's cache THROUGH the closed-form init: (a) key side — per kv head, fit `R* = rope_commuting_procrustes_paired` (rotate-half pair list `(i, i+32)`, i in 0..32) + `orthogonal_procrustes` on the non-rotary dim slice 64..256, taking producer post-gain pre-RoPE keys `k3` to consumer post-gain pre-RoPE keys `k7` over anchor tokens; the consumer's queries rotate by `R*ᵀ` applied post-gain (commutes with RoPE, so insertion point relative to RoPE is free — pinned as post-gain pre-RoPE for implementation determinism); (b) value side — per kv head, fit the rank-`n` value map `V_h` = Eckart–Young top-`n` (Gram + `katgpt_core::linalg::symmetric_eig`, deterministic Householder+QL) over anchor value pairs `v3 → v7`, folded into the consumer's output projection per q-head group (`O7 ← O7·V_h`). Rank `n` = 128 (half the 256-dim value head) PINNED; the rank sweep is a follow-up column, never a bar read.

**Fitting protocol:** anchors = `../riir-train/data/bonsai_mtp/tokens.fit.tokens` first 4096 tokens (the fit corpus, disjoint from the eval file by construction); teacher-forced pass capturing post-gain pre-RoPE keys + values at layers 3 and 7 (both kv heads). The gains are folded FIRST (anchors are post-gain — the constraint's "gain uniform within each pair or folded first" discharged by folding). Seeds: anchor selection = first 4096 in file order (deterministic, no sampling); all closed forms deterministic per Issue 940 + the `symmetric_eig` bit-identical contract.

**Eval protocol:** eval = `../riir-train/data/bonsai_mtp/tokens.chat.tokens` (14,075 chat-shaped tokens, sha256 `a59b90f0435dc7d863dbf4ae830228369fe9e97605a73dad93b4fcde9566fb13`, regenerable via `cargo run --release -p riir-infer-dist --example mtp_chat_tokens` — the Bench 924 family).
