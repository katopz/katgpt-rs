# Issue 1234: POC — symmetric-kernel Fourier latent embeddings (closed-form, Research 682)

**Status:** open — poc/proof task filed from Research 682 (arXiv:2602.15029); Gain-tier extraction, GOAT gates pre-registered below
**Claimed:** katgpt-rs-57@m3, 1795097735, expires 2026-11-21T14:15Z

Modelless extraction of the paper's symmetry→geometry theorem: a deterministic closed-form toolkit for **cyclic and ordinal latent coordinates** in `katgpt-core` — construct Fourier-feature embeddings FROM a translation-invariant kernel (frequencies AND amplitudes derived analytically), select embedding width from the kernel spectrum, read the latent coordinate back by phase, and detect ring/symmetric structure. Distinct from RFF (random frequencies, approximate) and sinusoidal PEs (fixed ladder, no kernel): the world's own statistics pick the modes. Consumes shipped neighbors only (`spectral/continuation.rs` lane, DEC detectors live katgpt-dec-side); zero new deps.

## Placement (explicit)

`katgpt-core/src/spectral/kernel_features.rs` (beside `continuation.rs`), behind opt-in feature `kernel_fourier_features`. Pure f32, fixed-width arrays, zero-alloc post-construction; construction itself allocates nothing (caller-provided output).

## Tasks

- [ ] **T1** `fourier_features_from_kernel` — periodic BC (integer `k_n = πn`, amplitudes from the periodized-exponential Lorentzian `a_n = sqrt(2σ/(1+σ²k_n²))`, discrete-L exact form) and open BC (Sturm–Liouville quantization `tan k = −σk` odd / `tan k = k/(1+σ(1+σ)k²)` even, solved by bounded bisection with a PINNED root bracket per interval — each quantization condition has exactly one root per mode interval and the bracket derives from those bounds, never a global search that could land the wrong root). Output layout: interleaved `(cos, sin)` pairs per mode; plain `[f32; 2w]` rows (no repr attributes, no wrapper types).
- [ ] **T2** `width_for_tolerance(σ, D, τ)` — smallest width `w` with kernel-spectrum tail energy < τ (closed-form geometric tail for the exponential kernel) + the Prop-4 decode bound `ε² ≲ r^(−1/D)` rendered as "dims needed for phase resolution δ".
- [ ] **T3** `phase_readout_into` — `atan2(⟨w_i, sin-mode⟩, ⟨w_i, cos-mode⟩)` recovering the latent coordinate from an embedding family (the latent→scalar boundary readout; callers sigmoid-gate where it drives behaviour).
- [ ] **T4** `conjugate_pairing_score` — symmetry diagnostic over a symmetric matrix's eigenvalues: fraction of the top modes that form matched sin/cos conjugate pairs (the paper's spectral fingerprint of translation symmetry). Report-only.
- [ ] **T5** GOAT gate `benches/` + tests, pre-registered falsifiers: **G1** full-width embedding Gram ≍ centered kernel on a synthetic periodized exponential (N=24, σ ∈ {1, 4.2, 12}); max abs diff < 1e-5 — a ROUND-TRIP pin only: at full width the Fourier basis exactly diagonalizes the circulant Gram for any σ, so G1 cannot fail by construction and gates nothing about the width law. **G1c (the width law's actual test)** at truncated width w < N/2: relative reconstruction error `‖K − Φ_w Φ_wᵀ‖_F / ‖K − mean‖_F ≤ 1.5 × sqrt(Σ_{n>w} a_n² / Σ_{n≥1} a_n²)` — the dropped-tail bound with 1.5× headroom PINNED before the first run (no post-hoc tolerance tuning), per σ **G1b** phase readout recovers each `x_i` within 1/(2w) at the truncated width. **G2** construction is O(N·w) (latency bar pinned at bench time, one quiet-box cell). **G4** zero-alloc on the hot path. **Falsifiers:** G1c mismatch at any (σ, w) ⇒ the kernel-spectrum width law is wrong there — demote the width claim in Research 682 §6, keep the construction; a G1b phase-readout failure ⇒ demote T3.
- [ ] **T6** (note-only candidate, not this issue's gate): Davis–Kahan demotion-safety readout for riir-refine corpus geometry (Research 682 §5-C) — file separately in riir-refine IF a measured consumer appears.
