## Core mechanisms (paper A)

1. Reasoning graph G=(V,E); combinatorial Laplacian L=D−A; GFT x̂=Uᵀx over the Laplacian eigenbasis.
2. **Chebyshev polynomial filters** h_θ(λ)=ΣₖθₖTₖ(λ̃) applied WITHOUT eigendecomposition: y=ΣₖθₖTₖ(L̃)x = K sparse matvecs (three-term recurrence), O(K|E|). λ̃ rescaled to [−1,1] (λ_max from Gershgorin = max degree; over-estimation only rescales the frequency axis).
3. **Spectral rule grounding ("rules as bands")**: each symbolic rule r ↔ a band template φ_r(λ). Transitive/smooth-propagation rules = low-pass; conflict/exception detection = high-pass. Composition Φ_total = Σ_r w_r Φ_r — because every template is a polynomial in the SAME L, composition is **coefficient merging**: θ_total = Σ_r w_r θ_r, then ONE O(K|E|) application serves any number of rules.
4. Symbolic bridge: pᵢ = σ(α(yᵢ−τᵢ)) — sigmoid threshold to predicates. **This is verbatim the house drive pattern** (sigmoid over a measured quantity, never softmax).
5. Interpretability: the frequency response h_θ(λ) directly shows which reasoning scales dominate.
6. **Stability**: polynomial filters are Lipschitz under graph perturbation; for Chebyshev specifically |Tₖ|≤1 on [−1,1] bounds the response by ‖θ‖₁. On a graph that mutates every tick (fog-of-war admits/drops edges), eigenvector-basis reads can rotate wholesale under a topology change while polynomial reads degrade boundedly → **design rule: polynomial reads on mutating think-brain graphs; eigen reads (hodge_decompose) reserved for static complexes (arena geometry, committed shards).**
