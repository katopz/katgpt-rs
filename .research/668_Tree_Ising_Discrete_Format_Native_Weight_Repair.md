## TL;DR

Tree-Ising is the **second optimizer successor** to the CSAIL agent on the SAME repair task (Qwen3.5-0.8B thinking-mode loops, layers 15/19, same agent-edit baseline, same eval harness) — posted the same day Barry's weight-space-lp landed in our stack (2026-11-10), an independent parallel evolution: **agent → {LP | Ising}**. Where the LP picks continuous per-neuron coefficients under linear push/keep constraints, Tree-Ising picks **discrete moves native to the stored weight format** — sign flips and ×2^k exponent shifts inside lossless-BF16 state trees, where every admissible move is exact in BF16 and touches only a sign bit + a 4-bit state, never a shared exponent or a mantissa (zero such writes **by construction of the move set**, not by luck). The objective — dose along `u = u_loop − β·u_end` + quadratic input-collateral `tr(Δᵀ C_P Δ)` + L0 budget — decomposes **exactly** into one dense QUBO (Ising model) per output row (2,048 rows × 512 spins), solved by seeded GPU simulated annealing or quantum-inspired simulated bifurcation; the same models are native input for quantum annealers/QAOA (8-variable PoC on IBM Heron, no advantage claimed).

**Results:** MATH-500@4 **54.6** (annealing) / **55.1** (SB) vs agent edit 51.7 same-harness (base 7.9 reported) — ahead on all five math benchmarks, Bonferroni-significant on MATH-500 and GSM8K; cut-at-cap 31.6%→23.9%; **112,630 changed weights** (13% fewer than the agent's 130,188), **278,767 BF16 bit flips (2.2× fewer)**, state-tree flips 4× fewer; **4 forward passes, 0 LLM tokens, $0.90, 31 min wall** vs the agent's $312/15.6 h. Reference-free transfer: Qwen3.5-2B greedy GSM8K **21.6→69.4** with layers and dose selected from the base model alone.

**Distilled for katgpt-rs (modelless, authoring-time):** the transferable primitive is the **discrete, format-native authoring arm for the shipped `weight_edit_overlay` carrier**: forward-statistics directions (loop + conclude) → move-set enumeration (exact in the declared weight format) → exact per-row QUBO → seeded deterministic solve → sparse per-element edit specs `ΔW[r,c] = (f−1)·W[r,c]` riding the existing COO/dequant-domain apply. On **ternary weights the move set degenerates to sign flips and 0↔±1 route flips** — Research 648 §4.5's "ternary sign-routing problem" gets its formal optimizer, and 648 caveat 5's third option (edits that never leave the stored format, no dequant→requant, no packed-quant perf-pin break) is now a published, measured recipe. ## 1. The mechanism (paper-verbatim numbers)

**Five steps:**

1. **State-tree moves.** Lossless-BF16 state tree (arXiv:2610.31931): each group of 64 weights shares one exponent node E; each weight stores a 4-bit state `D = E−e` + sign + mantissa (state 15 = rare escape). Move set `F = {−1, 2, ½, 4, −2, −4, −¼, ¼}`; admissible iff the group maximum is preserved (growth needs `D ≥ k`, shrink needs `D ≥ 1 ∧ D−k ≤ 14`) and no escape is generated — the shared exponent and every mantissa are untouched **by construction**. One move preselected per candidate weight ⇒ the edit is binary.
2. **Layer scan (forward-only).** Teacher-forced passes over the base model's own traces label four token sets: ℛ loop (repeated-8-gram windows), 𝒫 protected (pre-onset + correct-trace tokens), 𝒵 concluding (last 64 thinking tokens before `</think>` in correct traces), ℳ continuing (earlier thinking tokens). Directions: `u_loop ∝ h̄_ℛ − h̄_𝒫`, `u_end ∝ h̄_𝒵 − h̄_ℳ`, `u ∝ u_loop − β·u_end` (β = 0.5). Layer write score `s_ℓ = uᵀ(m̄_ℛ − m̄_𝒫)`; rule = two highest, **excluding the final layer**. The scan selects layers 15/19 on BOTH Qwen3.5-0.8B and 2B — matching the agent's choice autonomously (gradient-based attribution ranks 14/21/18/16 and FAILS to recover it). This closes the family's standing "layers inherited from the agent" caveat (648 §4, 664 §4.1 — Barry named heuristic layer selection his open piece), with the paper's own honesty: both models share the hybrid full-attention/linear layout and the exclusion rule was fixed after seeing the 0.8B scores, so the agreement may be architectural.
3. **Objective.** `E(Δ) = γ·dose + coll + λ‖Δ‖₀` with `dose = uᵀΔμ_ℛ` (μ_ℛ = mean loop-token inputs) and `coll = Σ_r Δ_{r:} C_𝒫 Δ_{r:}ᵀ` (C_𝒫 = protected-token input second moment — the layer-output reconstruction term of pruning/quantization). Target dose `= −τ|uᵀWμ_ℛ|`; τ = 6.7/6.1 on 0.8B (1.6× the agent's dose, calibrated on the practice screen), **τ = 6.5 for novel models** (base-model-only dose rule). γ set by bisection to hit the target; λ doubles until the weight budget holds (≤6 attempts). **Zero gradients anywhere.**
4. **Exact row decomposition.** K = 512 candidate columns per row (ranked by `|(uᵀW_{:j})μ_{ℛ,j}|`, row-independent). Per weight, preselect the admissible move with lowest single-weight energy; `δ_a = (f_a−1)W_{r j_a}`; the row QUBO is `E_r(x) = Σ h_a x_a + Σ_{a≠b} J_ab x_a x_b` with `h_a = γ u_r μ_{ℛ,j_a} δ_a + C_{𝒫,j_a j_a} δ_a² + λ` and `J_ab = δ_a δ_b C_{𝒫,j_a j_b}`. Exact given the retained columns and preselected moves (both heuristics that shrink the search space). 2,048 independent dense Ising problems, 512 spins each.
5. **Solvers.** SA: 16 replicas/row, 300 Metropolis sweeps, temperature 2→10⁻⁴·median|h_a| geometric, rows batched on one GPU. dSB: discrete simulated bifurcation, 1,200 steps, float64 single-flip descent after — **statistically indistinguishable repair** (55.1 MATH-500@4; no benchmark separates the solvers ⇒ the gains come from the formulation, not solver tuning). Greedy zero-temperature: 53.9 on the screen vs 57.0 full SA — wins but within the screen's ±4.4 resolution. QAOA on IBM Heron (8-variable block, p=2 best: 110/1024 optimum hits vs 4/1024 uniform control): PoC only, no advantage claimed; the paper's own Eq. 14 caps any faster solver's end-to-end upside at **1.40×** (the model-side forward passes dominate).

**The ablation that matters:** removing the conclude direction (β=0) drops the screen from 57.0 to **43.8** with 53% still cut at cap — suppression without conclusion. The `u_end` term is the single biggest objective driver, and **neither the agent edit nor Barry's LP had it** (the LP's constraints were push/keep only). Restricting moves to {−1, 2, ½} costs 7 points (50.0); budget 28k/layer costs 7.8 (49.2).

**Continuous control:** the closed-form rank-one minimizer of the same objective (`Δ ∝ −u(C_𝒫⁻¹μ_ℛ)ᵀ`, ROME-shaped) scores 57.8 on the screen — same accuracy — but changes **7.02M weights (62× more)** and 103× the bit flips. The objective, not the discrete solver, drives the gains; discreteness buys the format-native footprint. Plain directional ablation (`Δ = −α u uᵀW`): 38.3 — the collateral term is load-bearing.

1. **The sparsity axes are NOT comparable across arms — pin the metric.** LP wins changed-weights (16k vs 113k); Tree-Ising wins changed-bits (2.2× fewer flips, zero mantissa writes, exact-in-format). The paper's "which size matters" section is explicit: a rank-one edit is smaller *as an adapter* but rewrites 96% of stored values *as a patch*; a Tree-Ising patch leaves every unrelated stored bit untouched. Our fixture comparison (Issue 1209 T3) pre-registers BOTH axes (separation-per-changed-weight AND separation-per-changed-format-bit) and names changed-format-bits the primary, since that is the paper's differentiator and the one our packed formats care about.
2. **Format-native moves retire 648 caveat 5's third option.** Caveat 5: "our Bonsai-27B is PQ2 ternary-packed, where column edits need dequant→edit→requant (breaking packed-quant perf pins) or dequant-domain delta application." A ternary sign flip or 0↔±1 route flip **is** the dequant-domain delta — exact, no requant, no perf-pin break. On ternary weights the move set degenerates to exactly the flips 648 §4.5 predicted would be "arguably where this technique is strongest in our stack"; Tree-Ising supplies the objective + optimizer for them. GGUF block formats (Q8_0 block scales, K-quant super-block scales, PQ2_0) carry the shared-scale structure the state tree formalizes — a block-scale-preserving patch is the same construction one format over. The formats live in riir-infer (league checkpoints: `Ternary-Bonsai-2-27B-PQ2_0.gguf`, `Qwen3.5-0.8B-Base-Q8_0.gguf` — **the exact model family the paper repairs is already on disk here**); the carrier and gates live here.
3. **QUBO ≠ LP.** The quadratic collateral term is what makes the row problem a QUBO; Barry's LP could not express the pairwise couplings `J_ab`. Conversely the LP's per-token linear keep constraints have no QUBO row analog (Tree-Ising uses second-moment statistics instead of per-token constraints). The arms are complementary, not competing: continuous rank-1 vs discrete per-element.
4. **Family first real-model success.** After Issue 990's CLOSED-NEGATIVE fact-write, Tree-Ising is the family's first real-model, two-scale, statistically-significant validation of the repair class — on the same loop task the lane targets. It strengthens the 976 promotion veto's **author conjunct** (the pipeline is fully automatic: scan → stats → QUBO → anneal, zero LLM, zero GD) with external evidence at two scales. The **loop-class conjunct is unchanged**: no documented loop class in any served stack model (re-verified this session — the LAYA rung is single-question encoder serving, no autoregressive surface; instinct arena heads are tiny policy nets). The veto stands byte-identical; fixture-scale PoC only, per the 993 precedent.
5. **Determinism posture.** Annealing is stochastic; a stack port seed-pins replicas + runs sequential sweeps (Issue-809 global-RNG law, Issue-940 fold law) so same-seed ⇒ bit-identical emitted spec. Greedy single-flip descent (53.9 vs 57.0 on the paper's screen — inside its ±4.4 resolution) is the deterministic cheap incumbent; the fixture compares it FIRST and records the SA gap honestly.
