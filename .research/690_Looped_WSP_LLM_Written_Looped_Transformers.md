## 1. TL;DR

An LLM (Claude Opus 5.5, in a Claude Code session) sets **every weight of a small looped transformer by hand-written analytic formulas** — no gradient training, no fitting weights to labels (a brief-enforced rule) — and the loop is the scaling axis: **one block = one algorithm step**, run R times, so problem size buys loops, not weights. Reported results (the paper's claims; blog-only, unreplicated here): 100% of Maze-Hard 30×30 test — above every trained looped model (LDT 99.8% @ 1.8M params / 1,303 PFLOPs; EBR 94.1% @ 1,160 PFLOPs; frontier LLMs ≤ 26%) — and 100% of 60×60 and 100×100 self-generated mazes with the SAME weights; Sudoku-Extreme 141,040/141,040 (constraint propagation + backtracking, 40K loops, 17,014 weights); Tower of Hanoi 20 disks = 1,048,575 moves error-free (3,686 weights, ~2M loops); GraphWalks 256k–1M-token prompts 100% F1 (7,777 weights vs Claude 66.8%); parity ≤ 4,095 bits; reasoning chains; BBH/BBEH; CLRS-30 algorithms; SAT complete search; PlanBench — and **928 weights under a 1,000-weight cap still solve 100%**. The companion negative: **GD from random init on the SAME written architecture scores 0% in every configuration** (§5).

**Stack reading (one sentence):** this is the WSP family's proof that *from-scratch whole-model construction* scales where our landed lanes (overlay/edit ON a trained base) stop — and its construction grammar contributes exactly two new-to-corpus numerics primitives (Issue 1243) plus an external trigger-met for riir-train Issue 665's author-then-polish rung (T8 there).

## 3. The construction grammar (the extraction payload, each row with its signal-diff)

- **L1 — Exact-match attention heads.** Head score `-100·[(r_n−r_c−δ_r)² + (c_n−c_c−δ_c)²] + const(c)` → the intended neighbor outscores every other cell by 100; softmax mass `1 − O(e^−100)`; positional tables expanded analytically into the embedding (row, col, r²+c²; the quadratic-match trick `-s(y−x)² − s·P·penalty`). *Signal-diff:* the margin LAW ships — `margin_equilibrium(eps, FloatFormat)` + `precision_cliff` (Issue 959, verified `softmax_fix.rs` L43/L75/L91/L116) is exactly the checker for "is a constructed head's gap above the format's precision cliff" (Fp8E4M3 cliff 4·ln₂ ≈ 2.77 nats vs a 100-nat gap ⇒ ~36× headroom). New-to-corpus: the CONSTRUCTION instance + the audit-shaped composition → filed (Issue 1243 T2).
- **L2 — Snap activation τ(z) = ReLU(z) − ReLU(z−1)** — flat 0 for z ≤ 0, flat 1 for z ≥ 1 — with every argument engineered to ≥ 1.5 or ≤ −0.5, so any per-step numeric error below 0.5 leaves the output bit-unchanged ("2 million loops with zero drift"). *Signal-diff (narrowed per verdict round 1 — the reviewer's grep found shipped ε-dead-bands, coordinator-verified):* ε-dead-bands DO ship — `DEFAULT_GAP_EPS` (`katgpt-core/src/mux/height_gate.rs` L55, `dead_band_holds` test), `DEFAULT_QUANT_EPSILON` (`../riir-ai/crates/riir-engine/src/policy_cache/quantize.rs` L30, ±ε ternary sign dead-band), `katgpt-transformer/src/dense_mesh/adaptive_width.rs` — and `exact_sigmoid` (Bench 844) ships saturation exactness (accurate at the extremes, `exact_sigmoid(1.5) ≈ 0.818`, not invariant around them). What is genuinely new is narrower: **parking values deliberately ≥ 0.5 outside a [0,1] ramp so step-by-step error cannot build up over long loops** (the shipped dead-bands suppress noise near a boundary; τ's contract parks the state itself outside the ramp, invariant over an unbounded loop count), plus a **format-aware audit of that margin** (ULP × accumulation terms — no shipped dead-band checks its ε against the float format). Filed with the narrowed claim (Issue 1243 T1; the format audit is T2/T3's).
- **L3 — mod-k one-hot bounded state.** Distances stored as three binary remainders mod 3; the parity argument (grid neighbors differ by exactly 1 ⇒ d(c)+1 and d(c)−1 differ by 2, not ≡ 0 mod 3; mod-2 collides) makes state size independent of problem size. *Disposition:* real trick, no stack consumer (we store integers directly); recorded with its applicability predicate — the ±1-relation predicates stay mutually exclusive over Z_k iff the delta set is 2-torsion-free mod k — and the mod-2 collision as the pinned negative. Audited-observe.
- **L4 — Fixed-point loop discipline.** Once computed, extra loops change nothing (trained looped models overthink: DeepThinking 86% → <1% by loop 82); readout required identical at R_min / 2·R_min / 4·R_min; R = 2n covers any maze (a shortest path visits each cell at most once ⇒ 2n loops suffice). *Signal-diff:* our instances exist — Bench 699 T1/T2 measured `forward_looped` flat to T=1024 on the stable fixture (damping + radial/tangential toolbox, Issue 717), and riir-infer `mechanics_check` (verified `neuron_census_gguf.rs` L513 + the bin flag) pins band ≡ full bit-identity as a protocol gate. Difference in kind: ours are MEASURED properties of trained checkpoints; the paper's is a construction-time guarantee with an induction proof over loops. Corroborated; no new primitive.
- **M5 — deterministic first-index tie-breaks** (pointer order down, left, right, up; first qualifying neighbor wins). *Signal-diff:* Issue 940's law verbatim. Corroborated.
- **M6 — scratch clear-neurons** `s ← s − ReLU(s) + ReLU(−s) = 0`, erasing attention-copied values each loop. Recorded; no consumer (our kernels manage scratch explicitly).
- **M7 — AR state-from-history** (Hanoi: the board is recomputed from the emitted move list at every step — "errors cannot accumulate", no running tally). *Signal-diff:* the stack's deterministic-replay discipline is the same law offline (bench-algo resume bit-identity; quest-server op-seq replay defense; vessel identity). The paper's variant is per-step ONLINE recompute as error containment inside an autoregressive loop — no stack consumer serves AR puzzle loops. Audited-corroborate.
- **M8 — pointer-jumping doubling** (Shuffled Objects: each loop merges each position's swap record with the record 2^j back ⇒ log₂(#swaps) loops). *Disposition:* audited-discard — classic parallel composition, zero stack consumers (no lane iterates a function table to depth 2^20).
- **M9 — bounded saved-state backtracking** (Sudoku: 24 whole-grid copies in activation memory; a contradiction restores the copy with the guess ruled out; under-provisioned variants fail LOUD, never wrong-quiet). *Disposition:* audited-discard — engineering, not math; no consumer (the fixer's baseline→apply→revert is one deep, not a search). Revisit inside a future constructed-block arm.

**The GD negative, precisely (the paper's §4):** no-norm — 6 runs (3 lrs × 2 seeds), training collapses within 30 steps; +RMSNorm — six versions (1×/2× loops; 2/4 blocks per loop; 4×/16× width to 2.8M params), 8 h each on one H200, every version learns only to copy the input (87.4% trivial floor — ~1/8 of cells are on the path); + curriculum 10×10 → 30×30 (2,000 extra mazes) — 111 checkpoints, 0%; class-balanced loss ± aux supervision — 185 checkpoints, 0%; plain non-looped TRM-size transformer 46.3%; TRM itself 91.6%. Each GD run ≈ 5 PFLOPs (230–2000× less than the trained looped models). **Reading discipline: this is "GD fails in this budget on this architecture," not "GD fails, period"** — which is exactly why the constructed-init cell (T-1) is the live experiment and "give GD more compute" is not.

## 8. Reframes (the step-4 evidence)

**Game:** the maze wave — BFS distance spreading one ring per loop, mod-3 one-hot state, pointers with a fixed-order tie-break — is the fog-of-war belief spread's shape. Our `SpatialBelief` decays continuously (sigmoid) rather than converging to a fixed point, and the tick is raw/exact where a neural solver is barred. Verdict: no new game primitive; three corroborations (deterministic ties = Issue 940; bounded per-cell state = the fixed `[T; N]` discipline; idempotent steps = the FSM/stalemate doctrine).
**Consumer (rulewright, priority #1):** the E8 dead-band lint is a parse-shaped audit candidate — one line, recorded, no corpus action today.
