### A1. Temporal Mixture-of-Experts — Cylich, Fayyaz, Ndubuaku, Peng (NeurIPS 2026)

**Access:** MED — full abstract (neurips.cc/virtual/2026/170072); OpenReview PDF + API CAPTCHA-walled; no arXiv. Not in 571 (confirmed).

**Mechanism [P].** Sparse MoE activates K≪N experts/token, yet serving keeps the whole pool resident. Temporal MoE constrains the router so each token's expert set = the previous token's set with **exactly one swap-in** — the resident working set is exactly the active K-per-layer experts, and the single incoming expert loads from flash **overlapped with compute of the reused ones**. Pretrained from scratch: **5.1× serving-memory reduction** preserving **72–82% of the MoE-over-dense advantage**, consistent across compute-optimal 10¹⁶–10¹⁹ FLOPs. Probing: temporal routers attend more to **context than token identity**; per-expert usage spreads evenly. On RTX A6000 / laptop / Pixel 10a, an 11B keeps **66–83% of standard-MoE decode speed**. Post-hoc on frozen instruct MoEs is "remarkably robust" (best for sparser models); **~2 GPU-hours of distillation recovers most lost accuracy** (Gemma4-26B, Qwen3.5-35B). Unverified (PDF-walled): exact router math, swap-selection rule, distillation loss, overlap scheduler.

**Decomposition.** Modelless: the residency mechanism (deterministic systems), the **post-hoc constraint on a frozen checkpoint** (clamp routing to prev-set + top-1 new), the memory-scaling law, the probing diagnostics. Training-bound: from-scratch temporal pretraining, the 2-GPU-h recovery KD, probing heads.

**Prior art (agent search).** SwapMoE / Pre-gated MoE / MoE-Infinity / EdgeMoE / Fiddler / AdapMoE–MoE-CORE (2024–26) — all keep standard routing and *predict/exploit* locality systems-side. Delta: locality moves into the **routing policy**, making the working set exact-by-construction rather than predicted. Internal cousins: the `kernel_opt` MoE serving rules (expert-cache-write-path-regime-gated, compute-experts-before-router-lookup-fixup, counting-sort route permute) govern write/caching of a router-chosen set; none constrains the set ACROSS tokens.

**Verdict: Gain → issue-first.** Three leads, each tagged:
- **[P]** Temporal-residency `kernel_opt` rule: resident set = last tick's experts, one-slot monotonic swap (LaneSlot semantics), one prefetch overlapped with GEMV; demote-only env. ⛔ **Gated on naming an actual MoE league artifact first** — Bonsai-2-27B is ternary dense; no MoE consumer exists today. Parked until one does.
- **[ours]** Selection hysteresis latch: keep the previous lane/domain pick unless the new score beats it by a sigmoid margin; abstain ⇒ reuse. Mutated state = per-session last-pick + margin (stationary-surface test passes — state is named and mutated). Consumers: reflex `pick_domain`, instinct LRU eviction path. Feature-gated, byte-identical off. Not a paper claim — our analogy.
- **[ours]** Limelight-keyed brain residency: freeze/thaw follows the render-side limelight focus; thaw budget 1/tick, IO overlapped with the cognition tick. Consumers: riir-ai `freeze.rs` + neuron-db ShardIndex; generalizes the zone-crossing `warp_swap` staging into a continuous residency law. Not a paper claim.

**Weakest point:** abstract-level mechanism; fusion (2)/(3) are our constructions, and the paper says nothing about decision routing or game residency.

### A2. How Wide Is Attention? Measuring Its Effective Width in Tokens — Mosoyan, Ndubuaku, Mroz, Cylich, Shemet, Sandhu, Kumar, Lee (NeurIPS 2026 LCFM WS)

**Access:** MED — full author blog with complete math (henryndubuaku.fyi); paper PDF not located (workshop listing only). Not in 571 (confirmed).

**Mechanism [P].** Read an attention head as a runtime 2-layer MLP (W₁ = Kʰ cached keys, softmax across T, W₂ = Vʰᵀ). **Atomic effective width M̂_ε** = min |S| over REAL token columns such that a least-squares-refitted readout reproduces Y = AV within relative Frobenius ε (Eckart–Young unusable — its basis mixes all T tokens; the real-token constraint is what makes width context-dependent). Estimated greedily via **weighted block-pivoted QR**: score s_t = ‖(I − U_m U_mᵀ)A_:,t‖² (activation novelty) × ‖v_t‖² (value payload); take top-8 per block, orthogonalize, residual r_m = √(‖Y‖²_F − ‖U_mᵀY‖²_F)/‖Y‖_F — closed form, never forms W. M̂_ε = first block with r_m ≤ ε on **held-out queries** (every 4th held out; n = 16,384 sampled positions; ε the one hyperparameter; 6,144-atom cap, right-censored). Per-KV-head. Plus an **entropy-matched isotropic control**: replace each real query with a random direction β·u solved by 30-step geometric bisection for matched attention entropy; the ratio R_ε^ent separates dictionary-simplicity from query-distribution specialization. Findings: median width at T=16k, ε=0.2 — Qwen3-0.6B **168**, Qwen3-8B **1,032**; sublinear growth (log-log slope 0.23–0.46); dense models have a narrow **sink-dumping head population**; hybrids concentrate global attention into few wide heads (**Granite-hybrid has NO narrow heads**); ε-budgets give **9.1×/11× cache cut at +0.0067/+0.0212 nats** — yet **all width-budgeted conditions fail a needle test 10/10** (full oracle restore across all 288 KV heads needed).

**Decomposition.** Fully closed-form/modelless — pivoted-QR selection + LS refit + entropy bisection; offline on a frozen checkpoint; zero training. Self-declared caveats: upper-bound estimator; unsaturated at 128k; relative-Frobenius hides rare queries; expensive offline procedure.

**Prior art.** OBCache (arXiv:2510.07651 — optimal-brain KV pruning), ReST-KV (layer-wise output-reconstruction token importance), CAOTE (per-token eviction error, meta-policy over evictors). Delta: M̂_ε is an offline **measurement in token units** insisting on real cached atoms with refitted readout, plus the isotropic counterfactual — none of the cousins separate query-distribution specialization from dictionary simplicity.

**Verdict: GOAT-plan candidate → issue-first.** The lead: **per-layer ε-width census replacing the global sink pin (=4)** on Bonsai-2-27B — our sink pin is global (`.benchmarks/947/948`: 0.1297, incumbent pin 4, 1.7× the free-cluster top), and the paper shows sink-dumping heads are a *population* in dense models but **may not exist in hybrids** — a global pin is exactly wrong there. Proof path (named): (a) extend riir-infer `sink_audit`'s `HybridForwardScratch` capture from Q-only to **K/V** (⚠ plan-time check: the seam is described as a Q-capture; K/V exposure unverified in code); (b) run the pivoted-QR census offline (4090/bmo); (c) emit per-KV-head ε-window/sink budgets; (d) **⛔ MANDATORY needle-retention gate cell** — the paper's own lesson forbids loss-only gates (width budgets fail needles 10/10). This calibrates the **`kv_sink_window` that ALREADY SHIPPED** in the 841 §B-3 closure. **NOT licensed: runtime head-skipping** — the authors call this an expensive offline procedure, not a runtime algorithm; a per-head windowed-vs-full routing armed from census is the only league cell. Also feeds 571 row 8's Needle-2 window+sinks sizing (the 256-token window becomes ε-derived per layer).

**Weakest point:** distilled from the blog, not the PDF — appendix protocol (per-layer vs per-KV-head budget aggregation, calibration corpus) could differ; the sink_audit K/V seam is an unverified inference.

### A3. Whole-Model Quantization Below 4 BPW (CQ) — Mosoyan, Ndubuaku, Mroz, Cylich, Shemet, Sandhu, Lee, Kumar (NeurIPS 2026)

**Access:** HIGH on mechanism/numbers via two consistent co-author sources (companion blog henryndubuaku.fyi/blog/one-recipe-for-every-tensor + docs.cactuscompute.com/v2.2.2/docs/cactus_quants); OpenReview PDF `Q6FcVpI1SO` CAPTCHA/403-walled; no arXiv; venue ambiguous (LinkedIn: "ODI Workshop"; Cactus page: "NeurIPS · 2026").

**Mechanism [P].** One PTQ recipe for **every weight tensor of a multimodal model** — transformer linears, vision/audio towers, cross-modal bridges, per-layer embedding tables (PLI), shared token embedding. Five steps for activation-facing tensors: (1) SmoothQuant fold s_k = clip(diag(H)^α/|w|^(1−α), 1/8, 8), α=0.25, from ~2,900 joint multimodal calibration samples; (2) **fixed structured rotation** R_g = (1/√g)S₂H_gS₁P — fixed sign patterns + permutation breaking Hadamard row alignment (replaces QuIP#/TurboQuant randomness; offline needs no worst-case guarantee; zero storage); (3) FP16 group norm → unit sphere; (4) **ONE scalar Lloyd–Max codebook per (g,b), trained on a SYNTHETIC random-unit-vector distribution, shared across every tensor AND every model**; (5) GPTQ-style blockwise Hessian residual (damped Cholesky (H_s+λI)⁻¹, λ=0.01·mean diag). **Lookup variant** for no-activation tensors (PLI + shared embedding): per-row scale fit from sampled token ids, step 5 drops, plain NN; shared table rotated **whole-row** (row = semantic unit). b_eff ≈ b + 0.125. Kernel never unpacks: WHT on FP16 activation, fused codebook-LUT + norm-scale + matmul, one NEON pass (SDOT). Gemma-4-E2B embeddings alone are **60.6% of bytes** — no bundle goes under 4 bpw without them. Results: CQ leads at 3-bit everywhere (GSM8K 52.7 vs 21.9 best baseline; BFCL FP16-level); sole 2-bit survivor (ARC-E 50.8 vs 27.4); 2-bit vision tower holds ChartQA 48.4 vs ~14 collapse; Parakeet 2-bit WER 0.147 vs ≥1.0; production bundle **4.79 GB → 0.9 GB (~3.0 bpw)**; mixed precision (68 units@4 + 207@3 = 3.26 bpw) costs ~2 pts vs 7–15 for baselines. KV cache NOT in this paper (stays TurboQuant/.cact `kv_bits`).

**DELTA vs 568/571 — superset formalization with ONE SCOPED REVERSAL.** New vs 568 (.cact blog): SmoothQuant fold; Hessian residual pass; structured S₂HS₁P rotation; lookup variant + whole-row embedding rotation; multimodal towers/bridges; sensitivity-ranked mixed precision + bundle economics; benchmark suite vs GPTQ/AWQ/HQQ. The .cact FORMAT (196-B header, nameless dir, depth ladder) is NOT in the paper — stays blog-only. **Scoped reversal (verdict-corrected wording):** the paper reports "codebooks that differ by position gave no measurable improvement" — **under CQ's own recipe** (shared synthetic-distribution codebook + GPTQ-class Hessian residual, which may soak up the per-position gain). This does NOT close 571 row 11's "Bonus A/B: per-position vs joint codebook on the no-residual `TurboQuantKVCache`" — that A/B stays open for its own setting. QJL-drop-at-2-bit and the PLI 60.6%/4× numbers are confirmed/formalized.

**Decomposition.** Fully modelless-extractable: rotation closed-form; codebook = 1-D k-means on a synthetic distribution (model-independent); scale folds from calibration statistics; NN assignment; residual pass is Cholesky optimization over calibration activations. No backprop, no QAT.

**Prior art.** QuIP# (ICML'24 — E8 lattice + between-layer fine-tune, strongest 2-bit; CQ concedes that crown, competing on scalar-LUT/SDOT phone decodability); SAGE (arXiv:2610.14745 — newer 2-bit VQ); ternary/BitNet b1.58-class (different operating point). Delta: CQ's novelty is **scope** — whole multimodal model incl. the ~60% of bytes (embeddings) others leave FP16.

**Verdict: GOAT-plan candidates → issue-first + 571 amendment.**
- **[P]** **CQ3 league cell on the qwen3.8 dense lane**: never-unpack GEMV (FWHT on FP16 activation + int8 SDOT + per-(g,b) LUT centroids) vs llama.cpp Q3_K matched-bpw, pp2048/pp4096 + decode; per-family conditional retention (the lossy-surface promotion rule). **⛔ Matched-calibration arm REQUIRED** (verdict fix): CQ used ~2,900 joint multimodal calibration samples vs baselines' 128 text — the cell must run a matched-calibration arm or the multimodal margins do not transfer to our text lane. NOT Bonsai (ternary-trained = wrong input class; agent's caveat adopted). This closes 571's "four gateable primitives" CQ-W2A8 slot with the paper's full recipe.
- **[P]** **riir-rag embedding-index arm B**: whole-row rotation + per-row scale fit vs the plain `group_lut_at` arm; **gate = recall@k vs f32, never PPL** (our own standing evidence rule). Upgrades 571 row 11's GOAT-plan.
- **[P]** **Mixed-precision sensitivity ranking** as the tool behind the Q8/Q4 posture law: rank tensors by downstream-loss delta to pick which families stay Q8 — per-family conditional retention made mechanical.
- **[ours: hygiene]** **Lineage check**: Cactus's own "Bonsai 27B @ 3.9 GB, 1-bit QAT" line may share provenance with our league model's Bonsai-2-27B family — unverified name collision; one grep in riir-train lineage before ANY head-to-head with Cactus Bonsai numbers.

**Weakest point:** camera-ready unreadable — appendix-level content (ablations, formal statements) unverified; the calibration confound (2,900 vs 128) is the paper's own admitted bias, quoted margins carry it.

### A4. Cross-Context Neural Transport — Henry Ndubuaku, solo (NeurIPS 2026 NeuReps WS, PMLR)

**Access:** MED — author LinkedIn posts + one site line; OpenReview `0LpCp7UI2Z` CAPTCHA-walled both APIs; no arXiv; no Cactus blog (checked the index). Not in 571 (confirmed; the agent also flagged 4 of Cactus's 5 NeurIPS papers were absent from 571 — this batch closes that).

**Mechanism [P].** Question: most object-representation knowledge comes from fMRI during static pictures; the world moves — how much survives when input is a movie? 4 subjects scanned under BOTH conditions; **per-vertex tuning** (surface-fMRI vertex-wise encoding models) fitted on picture responses, **frozen**, then scored on how much of each vertex's movie response it predicts. Findings: (a) scene/place regions transfer best; (b) face regions transfer less; (c) **transfer is one-directional** — picture-fitted → film predictions work; film-fitted → picture predictions much worse. The transfer math ("coined mathematical models") is unverified — behind the wall.

**Decomposition.** Nearly all modelless: per-vertex linear/ridge fits (closed-form normal equations), freeze-and-apply, per-region transfer scoring, directionality comparison. Fit → freeze → score — the most modelless-compatible structure a paper can have.

**Prior art.** Tang et al. multimodal-transformer encoding models (cross-MODALITY transfer; delta: same-modality CONTEXT shift + the asymmetry finding); Gromov-Wasserstein brain/ANN alignment (fitted alignment maps; delta: frozen per-vertex model measuring survival, not aligning spaces).

**Verdict: Gain (small) → issue-first, parked on full text.** The lead **[P-instrument / ours-consumer]**: a **transfer probe for the decision harness** — fit-per-context (cal slice / traffic context) → freeze → per-class transfer + directionality scoring on the other context. This is exactly the metric rethink's Bench 089 banking77 caveat names ("the composed cal→test accuracy shift on the original distribution remains unmeasured") and gives ESC arming a principled pre-arming read that predicts the rate guard's out-of-window latch. ⛔ Parked until the PMLR full text lands (post-Dec 2026) — the transfer math is unverified; the game-side belief-transport analogy (zone-A-fitted direction vectors frozen into zone B, per-class transfer scoring) is **[ours]** and stays parked with it.

**Weakest point:** everything rides two LinkedIn posts + a site line — method summary, not equations; dataset identity unknown (possibly bespoke); all fusion is analogy.

### A5. Adoption-Gated Continual Learning (AGCL) — Mroz, Ndubuaku, Mosoyan, Sandhu, Shemet (NeurIPS 2026)

**Access:** HIGH — authors' full technical companion blog (henryndubuaku.fyi/blog/should-the-phone-adopt-the-model-it-just-trained — complete equations/tables/preregistration/limitations); OpenReview `DhLxxnCMhT` (published 2026-10-04) CAPTCHA-walled; no arXiv.

**Mechanism [P].** Adoption-gated swap of continual-learning candidates for FunctionGemma-270M-IT (full FT, vendor recipe, bf16 AdamW 1e-5, answer-tokens-only loss). Per cycle: **interaction** — incumbent θ answers greedily; user accepts/rejects; on rejection ONE sampled retry (T=1) from the **base** θ₀. Three bounded dedup FIFO sets keyed (command, answer): **T** train (1024, accepted), **A** acceptance held-out (128, kept OUT of training), **R** rejections (128); every k-th accepted entry (k=5) → A, rest → T, **never both** (an earlier double-filing of "recovered" examples contaminated scoring: candidate 1.000 vs incumbent 0.167). **Consolidation** — candidate θ′ = FT(**θ₀**, T), always from base, so a candidate is a function of T alone. **Gate**: score(m) = (1−α)·retained(m) + α·(1−repeated(m)) — retained = fraction of A reproduced exactly; repeated = fraction of distinct R-commands still emitted; serve the winner, **ties→candidate**; α=0 leans incumbent (its own greedy outputs fill A for free), α=1 grants mere change. Gate fail: incumbent keeps serving, candidate discarded. 27 preregistered runs, 3 domains (ALFRED/AndroidControl/MASSIVE templates, Zipf streams), perfect simulated user; floor held **27/27** on held-out verification; robotics 0.588→0.721, mobile 0.316→0.440 @ α=0.5; α=1 never beat 0.5; gate blocked 14/30 and 23/30 candidates; forgetting counted one answer at a time (lost entries 3→15→20 as α rises).

**Decomposition.** The ENTIRE gate is modelless — exact-match retention/repeat counts, α-projection, tie rule, bounded-set filing, decontamination, always-from-base construction; zero learned components; pure data plumbing over an outcome stream. Candidate PRODUCTION is training-bound (full FT), but the gate is **producer-agnostic** — any whole scoreable artifact qualifies (engram delta, deterministic LoRA overlay), making the loop modelless-compatible.

**Prior art.** Thomas/Theocharous/Ghavamzadeh ICML 2015 (high-confidence policy improvement via distributional bounds — delta: AGCL swaps the bound for exact empirical rates computed on-device, inside the loop); ReST/STaR/KTO (feedback filters DATA, serve decision stays external); Hoy et al. 2025 STABLE + FLAIR + SPRInG (constrain forgetting DURING training; delta: **nobody gates the SWAP on held-out accepted behaviour — EWC penalizes, AGCL refuses**).

**Verdict: GOAT-plan (gate primitive fully modelless) → issue-first.** The batch's priority-1 lead: **the measurement axis our promotion discipline lacks.** Our GOAT gates measure benchmark deltas; score-bench and the regime monitors measure aggregate heal-rate and selection distribution — **nothing measures post-swap retention of previously-accepted outcomes + repeat-of-previously-rejected outputs per swap** (signal-diff checked). Leads:
- **[P-gate / ours-consumers]** **Adoption/retention regression gate for promotion swaps**: post-swap retention + repeat-of-rejections on live outcome streams (fix trajectories, oracle verdicts), bounded FIFO sets (`RingRow<T,32>` shape exists in riir-neuron-db), never-double-file decontamination, always-from-base candidates, ties-to-challenger. Consumers: riir-refine active-set changes + `seat_rerank` head swaps; instinct LaneSlot epoch swaps. ⛔ **GOAT = gate-on vs gate-off on the real store**; the simulated-perfect-user gap is inherited — our judges (compile-pass, oracle verdicts) are noisy, α=0.5 under judge noise unmeasured. May fail honestly.
- **[ours]** **Adoption-proof sidecar on the freeze envelope**: A/R digests + gate score + lost-count ride the envelope like `AnchorSidecar`; an unevidenced snapshot refuses loud — **sibling of the calibration-staleness seam that SHIPPED** in 841 §B-3 (`2057ac3b`). The AGCL rule "calibration binds to the base model" (571 row 3) and this adoption proof are the same family: evidence must bind to the exact weights being served.
- **[P]** **Adoption-gated engram delta** (571 row 8's modelless fine-tune candidate, now with its gate): candidate = `StagingEngramTable` delta from accepted interactions; gate = retention/repeat over held-out engram lookups; freeze-envelope commit only on gate win.
- **[P]** riir-train accept-only SFT lane → appended to 561 (the only training-track item this batch adds).

**Weakest point:** gate validated only against a simulated perfect user (authors' own admission) — our fusions inherit exactly that; the α=0.5 sweet spot under judge noise is unmeasured, and the gate-on/gate-off cost on real stores is extrapolation from a 270M tool-calling domain.
