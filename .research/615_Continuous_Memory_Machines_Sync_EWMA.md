## TL;DR

arXiv:2610.07907 "Continuous Memory Machines" (Regan, Arulkumaran, Darlow, Druga, Risi, Jones — Sakana AI / Tsukuba, NeurIPS 2026 + PALM workshop) extends the Continuous Thought Machine (CTM, arXiv:2505.05522, NeurIPS 2025 spotlight) with a matrix-valued Long-Term Memory (LTM) jointly updated with the CTM's short-term activation window by a small Transformer (J=1–8). Four transferable primitives survive the modelless decomposition: (A) the **synchronization EWMA** as an online second-order co-activation memory over bounded belief dims — stored as raw `S = E_w[zz]` + weighted mean `m` per bank, with the covariance computed at readout as the MASS-NORMALIZED exact form `C = S/mass − (m/mass)⊗(m/mass)`; two readouts: `δ_level = Σ|C_ij|` (coupling state → hysteresis/salience) and `δ_surprise = Σ_ij|C^fast_ij − C^slow_ij|` (relation CHANGE, the second-order dual-EMA — free from the K=3 ladder); a per-entity *relation* signal no shipped module produces; (B) the **A.3 horizon-invariance law** (normalize windowed summaries by the linear weight sum, never its sqrt; split mean from mass) — load-bearing here: without mass normalization the covariance is wrong at small n; (C) the **learned sink token** as an explicit SUPPRESS arm in memory-read gates; (D) **per-channel temporal filters** (the NLM's closed-form analog: Yule-Walker α_i = c1_i/c0_i). The two-timescale CLS framing itself VALIDATES shipped design (dual fast/slow EMA surprise kernel Plan 277, Raven/δ-Mem consolidation, freeze/thaw, two-brain model) — citation, not action. Training track: applicable, Plan 453 filed (ParaRNN enabler, learned decay-constant tables, CMM-shaped NPC head).

## 1. Paper core (21 pp., code public: github.com/SakanaAI/continuous-memory-machines)

- **CTM recap:** synapse FFN → pre-activation a_t appended to sliding STM A_t ∈ R^{d×MS}; per-neuron MLPs (NLMs) map each row of A_t to next state z_{t+1}; latent = *synchronization* S_ij ∝ Σ_τ e^{−r_ij(t+1−τ)} z_τ^i z_τ^j (per-pair learned decay); output = W_out·vec(S).
- **CMM delta:** persistent LTM B_t ∈ R^{d×ML}; each step, [sink; B; A] → J Transformer blocks → updated B̃, Ã; NLMs read Ã; B̃ carried forward. Bidirectional read–write: each store reorganizes itself and reads the other.
- **Results:** algorithmic tasks (copy/recall/sort) beat DNC/NAM-TM/CTM (CTM's 60×-worse recall confirms the short-window limit); maze-solving 96.3% action / 61.6% full-maze @10M params (CTM 88.8/37.4) preserving interpretable attention; few-shot regression best (30.6% vs CTM 8.8% @K=20); sort length-gen 72.1% @N=50 (train ≤16).
- **Analysis (fig. 6):** task-dependent memory strategies — copy: STM queries read LTM; sort: self-attention during output; **maze: STM queries attend ENTIRELY to the zero-value sink**, bypassing both stores. The model learns when memory is irrelevant.
- **Training details that matter:** CTM backbone > LSTM backbone for the same LTM+Transformer; J=2–4 optimal; larger LTM helps when STM restricted; residual gates γ_j=0 (identity start) for maze/parity; learned B0 ~ N(0,0.01²); pos-emb on Q/K only, sink V zeroed per block; **A.3: remove the sqrt from the sync normalization** — linear-sum denominator makes the summary's magnitude horizon-invariant ("generalize to thinking horizons beyond those seen during training"). Compute: single H100, 0.6h (parity) … 127.5h (maze) per seed.

## 3. Fusion (what the combination produces that none has alone)

**CMM sync × Plan 277 dual-EMA × outer-product SIMD × KG-triple social law** → the stack's first per-entity **relation memory**: the SIMD outer-product accumulator already ships (`simd_outer_product_acc`, `katgpt-types/src/simd/dot.rs:351`, `_scaled` variant at :512 — re-exported `katgpt_core::simd`; the GDN2 lane is a use-site); reused as a mass-normalized covariance store it yields two relation scalars — `δ_level` (coupling state; gates KG-triple formed/released hysteresis and salience via `argmax_ij|C_ij|`) and `δ_surprise = Σ|C^fast − C^slow|` (relation change; gates write-through). None of the four ingredients produces a relation signal alone: 277 is first-order value surprise, GDN2 stores key–value associations for sequence readout, the KG path uses instantaneous similarity, consolidation averages events. **This composition is the GOAT claim.** δ_surprise is blind to pure marginal movement by construction (the G1a controls pin it), which is exactly the discrimination the novelty sentence claims.

## 4. Game-context reframe (step 4 — mandatory)

*"Our NPCs notice when relationships change before any single belief moves."* Pack cohesion, rivalry decay, trust erosion are RELATION-level phenomena: two belief dims co-activating (hero-near + ally-near) that decouple ("ally stopped following") is a relation event invisible to first-order surprise if neither belief moved much. SyncBank turns that into one scalar; the 5-scalar sync law carries it across the boundary, never the D² matrix. Bounded cost: D=8 → 64 accumulators/entity; D=64 → 4,096 (≈µs-class NEON observe) — limelight-gated to HOT/WARM entities, COLD entities carry no SyncBank. Physical domain untouched (raw MapPos stays raw; anti-cheat never sees latents).

**Consumer-context (healer, priority #2):** weaker fit, stated honestly — the healer's fix-trajectory store (`traj_store.rs`, Elo + Beta selection) already owns sequence-structured memory, and lint fixes are one-shot spans where relation-surprise has no measured consumer. The one candidate: a SyncBank over rule-family activation streams as a corpus-staleness drift detector (families that used to co-fire and stopped). Recorded as a follow-up idea in Issue 930's notes, NOT filed as work — no gap document names it, and inventing a consumer is the N1-class error the training advocate flagged.

## 7. Validation protocol (if/when Issue 930 GOATs)

- **G1a (primitive-level, synthetic, no replay needed) — asserted on δ_surprise:** arm (a) correlation flips sign (+ρ→−ρ) or drops to zero with marginals held → δ_surprise MUST spike on both (Σ|C| alone cannot: a flip dips through zero and returns to the same level — this is why the split exists) and settle after the change; arm (b) negative control: marginals shift INDEPENDENTLY (one dim steps, or two dims step at different ticks with independent noise — co-movement of both dims at the same tick is real relation signal and must NOT be used here) → δ_surprise stays quiet once the per-dim means settle (~3/d ticks per bank). Pass both arms or the primitive is mislabeled.
- **G1b (real fixtures, gates promotion to default):** replay fixtures with known relation-flip events (plan-333 harness / raw_wake_cycle captures); paired δ_surprise detection vs the Plan-277 baseline, Wilson bounds; unarmed = bit-identical (G3 by construction). If fixture labeling stalls, the lane ships opt-in on G1a alone and G1b stays the promotion gate — never skipped silently.
- **G2:** ns/observe at D=8 and D=64 (`--release`, belief_dual_bench harness shape); cost is stated absolutely — K·D(D+1)/2 FMA + same-order |·| ops (upper-triangle symmetric storage) — not as a ratio to another lane.
- **G3:** feature-off build bit-identical.
- **G4:** counting-allocator zero-alloc.
- **Exactness arm (rides T3):** the mass-normalized estimator is EXACT — assert C matches a batch weighted covariance to ≤ 1e-5 on a fixed stream.
- **Lean option (the trained paper cannot write this):** `sync_bounded` — z_i ∈ [0,1] ∧ exact weighted covariance (mass-normalized) ⟹ C_ij ∈ [−¼, ¼] (Popoviciu-class bound; the bound holds ONLY for the mass-normalized form — the lagged incremental estimator violates it, which is why that form is banned). One line in `.proofs/RiirAiProof` style + Rust spec-match.
- **Demote-the-loser:** if δ_surprise detection ≈ value-surprise detection, record the negative and delete the flag; the Plan-277 kernel stays.
