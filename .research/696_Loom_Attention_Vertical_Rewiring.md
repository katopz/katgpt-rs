## TL;DR

Transformers fix head-to-head composition at training time through **virtual weights** C̄_ij = W^O_i·W^s_j; attention makes the *horizontal* (token) flow input-dependent while the *vertical* (depth) flow stays static — a model needing different circuits per input keeps them all wired and gates them only indirectly (attention sinks). Loom attention lets a head choose which earlier heads to read from **at every token**, exactly as it chooses which tokens to attend to, by interweaving vertical attention over earlier-head outputs with horizontal attention over tokens. Naive per-reader attention over all earlier heads costs Θ(n²L²) — unaffordable — so vertical attention is instantiated as **normalized + gated linear attention over a per-token matrix memory** M ∈ R^{d_k×d}: writers store compressed outputs via outer products (ΔM = k^m ⊗ o), readers read via u = q^m·M, both ports generated **per head per token** from the vector stream. M accumulates along depth → a second residual stream; vector stream carries **control** (ports + RoPE routing), matrix stream carries **content** (all attention-moved values, read from M alone). Result: matches Transformer++ at 3.19–3.25× compute and the four residual-stream baselines (DHC/mHC/AttnRes/MUDDFormer) at 1.73–2.76×, at 2.0–3.7% extra FLOPs; LoomPythia-2.8B (300B Pile, +1.95% FLOPs) = 1.6× mHC-Pythia's downstream gain, matching Pythia-12B 0-shot and beating it 5-shot (61.6 vs 60.8) and on FLAN ppl (6.94 vs 7.26).

## 1. The mechanism (our vocabulary, paper Eqs. 4–7)

| Piece | Paper form | Notes |
|---|---|---|
| **MWrite** | k^m = RMSNorm(x^w W²_W) ⊙ σ(x W^W_g); ΔM = k^m ⊗ o | Linear-attention outer-product write; port = d_k vector (d_k = 2n slots), Norm separates slot *direction* from gate-separated *magnitude* |
| **MRead** | q^m = Norm(x^r W²_R)⊙σ(x W^R_g) + q̄⊙σ(x W^R_ḡ); u = q^m·M | Dynamic + static query branches, both sigmoid-gated; read cost independent of depth (d_k slots, not nl writers) |
| **MShift** | M̃ = MNorm(z⊙M[t−1] + (1−z)⊙M[t]), z = σ(x W^S_g) | The only cross-token channel; gated mix of previous-token memory. Ablation: removing MShift retains **94.2%** of the gain — small but real |
| **LoomMHA** | o_i = o^m_i + Attn(q_i,k_i,v_i) under **strict causal** mask (self excluded); ΔM = Σ_i MWrite_i(Norm(o_i)) | q,k = RoPE(x·W^{Q,K}) ∥ (q̃,k̃) — RoPE coordinates (d/4 dims) do token routing; **v comes from M alone**; the bypass o^m carries self-content |
| **FFN_M write** | ΔM = Σ MWrite_i(split_i(FFN_M(x))) | The only post-embedding channel from vector stream into M; removing it hurts most (80.7% retained) |
| **Sizing** | d_k = 2n slots (M = 2D) + D vector stream; vs HC's 4D | Smaller state than 4-stream HC/mHC at higher wiring rank |

**The wiring theory (the paper's real contribution beyond the architecture):** every residual-stream mechanism's per-token wiring matrix C ∈ R^{w×r} has a **rank** — Transformer/DenseFormer/HC/mHC/AttnRes are **node-gated** (C = g·g′ᵀ, rank ≤ 1: they can only switch whole rows/columns, realizing only *rectangular* patterns — non-rectangular ones either interfere (dense virtual weights) or are unreachable (sparse)); MUDDFormer reaches rank 3 (per-Q/K/V ports); LoomFormer generates ports per head per token → rank min(d_k, 3n) = 2n, one head per reader, realizing arbitrary patterns up to d_k writers. **Theorem 2.4** prices node gating: to avoid circuit interference a node-gated reader needs N(w, r−1) reserve heads = **Θ(w)** at practical sizes (a cover-free-family / non-adaptive-group-testing bound) — the formal reason "more heads" cannot buy rewiring.

**Identity-at-init** (the pattern Research 691 §3 E1 prized, independently rediscovered here): gate biases initialize the dynamic read branch at 0.05, static read 0.9, write 0.1, MShift 0.5; q̄ = 0 for q̃/k̃/o^m so memory-read Q/K coordinates and the bypass **grow in gradually** from a static-port start. Training starts as ≈Tfm_{K,Q} + static ports and rewiring is learned on top — the paper's own stability mechanism ("initializing dynamic port gates near zero so training starts smoothly from static ports").

## 2. The attention-sink theorem (the bridge to our sink-audit lane)

Proposition 2.3 + Theorem 2.4 give a **mechanistic explanation for attention sinks**: in a node-gated model, a head whose fixed input wiring is not needed at a token can only turn itself off — and it does so by attending to a sink token (output ≈ 0 kills both its writer and its readers). The paper then measures it: deep layers 17–32 non-sink ("on") heads = **22.9%** (Pythia-2.8B) / **17.7%** (mHC-Pythia) vs **74.4%** (LoomPythia) — 3.3×/4.2× — with first-two-token sink mass dropping 26.4%/27.2% → 1.5%, and traces the 5-shot/FLAN gains to this freed capacity (in-context rewiring case study: at hub layer 19, `"Germany"` wires key/value/bypass reads from L13/L08 heads; one token later at `":"` those switch off and the layer rewires onto causal q̃ + o^m pathways; freezing the dynamic ports at the stale token drops P(" Berlin") 0.65 → 0.54).

**Workspace connection:** riir-infer's sink-audit census (Research 026 lineage; the live lane is riir-infer Issue 1180 — [`.benchmarks/953_i1180_t1_gemma2_ungated_sink_census.md`](../riir-infer/.benchmarks/953_i1180_t1_gemma2_ungated_sink_census.md); katgpt-rs Issue 981 closed `5ad264521`, its founding cells riir-infer `.benchmarks/947/948`) already measures sink-class head behavior on GGUF checkpoints and recorded Bonsai-2-27B at 0.1297 UNDECIDED.
