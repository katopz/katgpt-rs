#
# ⛔ Do not "fix" a red by raising a ceiling. Rust binds an attribute to the
# next item ACROSS a blank line, so a new row means some item is silently
# cfg-gated and some other item silently is not. The canonical instance cost
# two days of broken release builds in katgpt-pruners (`26d055c6` dropped the
# `use` the attribute applied to; the attribute re-bound to the next import;
# every `--release --features sdar_gate` build failed with 5 errors; the
# introducing commit's own validation was a DEBUG run, where `debug_assertions`
# is on and the import exists). And `7e34ccef` then deleted the blank line,
# which made the wrong binding look deliberate — read what the attribute USED
# to apply to before touching the whitespace.
#
# ── BOTH floors, and both bite everywhere here ──────────────────────────────
# max_offenders = 0 is green over whatever the walk can SEE, and the walk
# shells out to `git ls-files` — a regression takes the population to 0 and the
# ceiling passes, indistinguishable from a clean repo.
#
#   min_rs_files   moves when the WALK goes blind
#   min_cfg_sites  moves when the REGEX breaks on an unchanged tree
#

# subprocess_encoding_drift_floors.txt, where min_calls is 0 in 10 of 16 repos
# and detects nothing in most of the population. Here both quantities are
# NON-ZERO in all 16 — the smallest, riir-viewbridge, has 24 tracked `.rs` and
# 20 outer-`#[cfg]` sites. Do not carry one repo set's warrant onto another.
#
