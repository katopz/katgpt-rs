# Pins for scripts/issue_citation_gate.py (landed 2026-09-12).
#
# Two floors, not one. A ceiling is green over whatever the instrument can SEE,
# so the finding count needs the POPULATION that produced it, and the
# population floor needs the WALK size underneath it — the workspace rule.
#
#   min_repos              the derived contract-repo set (BOUNDARY.md + .git).
#                          Below this the sibling-ownership lookup is empty and
#                          every cross-repo citation reads as "NO REPO", or the
#                          repo-name context test never matches. Workspace was
#                          19 at landing; floored well under to leave room for a
#                          repo legitimately leaving the contract.
#   min_citations_scanned  the citation regex's own walk. A regex regression
#                          (a Python \s handed to an ERE, the classic) takes
#                          this to 0 and prints a confident clean. 105 at
#                          landing across the two documents.
#
# There is deliberately NO ceiling on the AMBIGUOUS count (numbers cited here
# that exist BOTH locally and in a sibling, so the referent is undecidable from
# the number — 63 at landing). The gate is green over them by construction, and
# a ceiling would red whenever somebody writes a CORRECT citation to a new
# local number a sibling also has. It is printed every run instead, so a green
# is never read as a green over everything.

min_repos = 15
min_citations_scanned = 80
# (no ambiguous_ceiling: the blind spot is REPORTED, not gated — see the gate docstring)

# The documents this gate reads. A pinned list, not a walk: a walk of *.md
# would pull in .plans/.docs/.research (thousands of by-design local citations)
# and drown the signal. AGENTS.md is the contract a new agent reads; HISTORY.md
# is where a resolved issue's narrative outlives its file.
documents = AGENTS.md HISTORY.md

# ── the width bound's own liveness (Issue 753) ───────────────────────────────
# `\d{2,4}` deliberately cannot see `Issue 6`. That was measured at 0 in this
# scope ONCE (Issue 751 T2b) and never re-asserted — a dated measurement over
# documents five-plus concurrent sessions edit daily. Widening the bound is NOT
# the repair: measured over every tracked .md in the workspace, `\d{1,4}` would
# manufacture 51 false citations from section numbering (`## Bench 1:`) and 0
# true ones. So the bound stays and the CLASS is watched instead.
#
# A breach is exit 2, not exit 1: the prose did not get worse, the scope grew a
# form the verdict regex cannot read, so a clean verdict stopped covering it.
max_single_digit = 0
