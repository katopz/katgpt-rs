# Pins for scripts/python_syntax_floor_drift_sweep.py — EVERY contract repo.
#
# Format, 4 whitespace-separated fields:
#
#   <repo> <min_py_files> <min_parsed> <max_syntax>
#
# Re-pin DELIBERATELY, in the commit that changes the measured value, with the
# reason in the commit message. A pin that drifts behind reality is a pin
# nobody trusts.
#
# ⛔ There is deliberately NO max_unparsed column: the HEAD rescan cannot
# classify a blob that parses at no grammar, so an UNPARSED ceiling fed from
# delta.head would be dead plumbing that only looks like it works. UNPARSED is
# a DIRECT FLAG on the worktree scan in the sweep (the subprocess_encoding
# sweep's identical shape) — same wall-at-zero red, one honest mechanism.
#
# ── the ceiling is a WALL, not a ratchet ─────────────────────────────────────
# max_syntax is 0 in every measured repo (2026-10-26), and that zero is
# EARNED: the landing census ran the 3.9-grammar parse over all 391 tracked
# .py on this box and found exactly ONE live site — reflex-site
# scripts/render_flows.py (a PEP 701 f-string backslash, 3.12-only; the
# feature-grep census that closed Issue 965's class missed it, the grammar
# parse did not) — fixed a24f4dd the same day. There is no DELIBERATE class
# here: a file that cannot parse cannot run. Do not raise the ceiling; the
# repair is rewriting the construct.
#
# ⚠ A SYNTAX finding is not visible on the box that lands it when that box
# runs a newer python: the file imports fine there and only the floor parse
# sees it. That invisibility is the reason this is a pinned sweep and not a
# sweep-and-done.
#
# ── BOTH floors, and what each one moves on ──────────────────────────────────
# A ceiling of 0 is green over whatever the walk can SEE, and the walk shells
# out to `git ls-files` — a regression takes the population to 0 and the
# ceiling passes, indistinguishable from a clean repo.
#
#   min_py_files  moves when the WALK goes blind
#   min_parsed    moves when the SCAN LOOP stops iterating early on an
#                 unchanged tree (in every passing state parsed == files —
#                 any file failing the floor parse is a finding above)
#
# Both are pinned and neither is derived from the other — they fail in
# different blind modes.
#
# Floors are ~50-60% of measured where the count is large enough for that to
# mean anything; at MEASURED for the small/new rows (the reflex 2026-09-21
# birth precedent — re-pin at the first re-measure). katgpt-rs's two floors
# are NOT free: they must equal python_syntax_floor_gate.FLOOR_PY_FILES /
# FLOOR_PARSED, and the sweep ASSERTS that rather than trusting it.
