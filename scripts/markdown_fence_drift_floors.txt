# Pins for scripts/markdown_fence_drift_sweep.py — EVERY contract repo.
#
# Format, 3 whitespace-separated fields:
#
#   <repo> <min_md_files> <max_unterminated>
#
# Re-pin DELIBERATELY, in the commit that changes the measured value, with the
# reason in the commit message. A pin that drifts behind reality is a pin
# nobody trusts.
#
# ── the ceiling is a WALL, not a ratchet ──────────────────────────────────────
# max_unterminated is 0 in all 20 repos (2026-09-12), and that zero was EARNED:
# Issue 756 took the workspace from 19 files / 611 swallowed lines to zero in
# one day, across katgpt-rs (12), riir-ai (5) and riir-train (2).
#
# ⛔ Do not "fix" a red by raising a ceiling. A new row means a document renders
# half of itself as a code listing AND a fence-scanning gate downstream of it
# mis-phases and thereafter scans the complement — reporting clean either way.
# The repair is one fence.
#
# ⚠ And the reported line is the DANGLING fence, not necessarily the defect: a
# single stray fence inverts the pairing of every fence after it. Two of
# riir-train's repairs were 495 and 21 lines UPSTREAM of what was reported, and
# riir-ai/094's needed the OUTER pair widened to ```` rather than the "extra"
# fence deleted — deleting it leaves the inner code rendering as prose forever.
#
# ── the ONE floor, and why one is enough here ─────────────────────────────────
# max_unterminated = 0 is green over whatever the walk can SEE, and the walk
# shells out to `git ls-files` — a regression takes the population to 0 and the
# ceiling passes, indistinguishable from a clean repo.
#
# min_md_files is the quantity that moves when that happens, and unlike the
# trap sweep's population floor it is NON-ZERO in every repo (the smallest,
# riir-kat, has 3), so it bites everywhere and a second floor would add nothing.
#
# All floors are ~55-60% of measured: SLACK against churn (archiving a .plans
# tree or removing a resolved-issue batch legitimately shrinks the count, and a
# floor that ratcheted to the last measurement would red that cleanup and teach
# whoever hit it that the sweep is noise), TIGHT against blindness (a walk
# regression drops these by an order of magnitude, not by a third).
#
# katgpt-rs's min_md_files is NOT free: it must equal
# markdown_fence_gate.MIN_FILES, and the sweep asserts that rather than
# trusting it — same quantity, two files.
#
# ── no membership pin here, deliberately ──────────────────────────────────────
# trap_sentinel_gate.py pins its set by NAME because a count is not a checksum
# over a set. That does not apply here: the verdict is DERIVED from the file's
# own fence structure and there is no repaired-file list to lose. Every way to
# reintroduce the defect lands on max_unterminated; every way to go blind to it
# lands on min_md_files.
