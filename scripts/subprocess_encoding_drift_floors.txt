# Re-pin DELIBERATELY, in the commit that changes the measured value, with the
# reason in the commit message. A pin that drifts behind reality is a pin
# nobody trusts.
#
# ── the ceilings are WALLS, not ratchets ─────────────────────────────────────
# max_decode and max_child are 0 in every measured repo (2026-09-14), and that
# zero was EARNED: Issue 783 took the workspace from 29 DECODE + 2
# CHILD-ENCODER to zero in one change —
#
#   riir-train 12+1 · riir-clippy 9+1 · riir-ai 6 · riir-dapps 1 ·
#   mmorpg-editor 1
#
# ⛔ Do not "fix" a red by raising a ceiling. The repair is two tokens:
# `encoding="utf-8", errors="replace"` on the parent's read, and
# `env={**os.environ, "PYTHONIOENCODING": "utf-8"}` on a `sys.executable`
# child. A ceiling above zero on a class that cheap teaches whoever reads it
# that the class is tolerated.
#
# ⚠ And a red here is not visible on the box that lands it: macOS,
# ubuntu-latest and the M3 are all UTF-8, so nothing that could NOTICE this
# class ever runs it. The failure is either silent mojibake (rc 0, a plausible
# string, and a caller's em-dashed regex matching nothing — a confident zero
# findings) or `stdout = None` with the returncode PRESERVED, because the
# decode raises inside subprocess's reader THREAD where the exception dies.
#
# ── BOTH floors, and why the walk floor carries the weight here ──────────────
# A ceiling of 0 is green over whatever the walk can SEE, and the walk shells
# out to `git ls-files` — a regression takes the population to 0 and both
# ceilings pass, indistinguishable from a clean repo.
#
#   min_py_files  moves when the WALK goes blind
#   min_calls     moves when the AST PASS breaks on an unchanged tree
#
# ⚠ min_calls is 0 in 10 of the 16 repos measured — those repos have `.py`
# files and no `subprocess` at all — so unlike the fence sweep's single
# `min_md_files`, the parse floor cannot carry the blindness argument by
# itself. In exactly those repos min_py_files is the only detector there is,
# which is why both are pinned and neither is derived from the other.
#
# Floors are ~50-60% of measured where the count is large enough for that to
# mean anything: SLACK against churn (retiring a plan's scripts legitimately
# shrinks the count, and a floor that ratcheted to the last measurement would
# red that cleanup and teach whoever hit it that the sweep is noise), TIGHT
# against blindness (a walk regression drops these to 0, not by a third).
#
