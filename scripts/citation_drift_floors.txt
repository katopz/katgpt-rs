# Pins for scripts/citation_drift_sweep.py — EVERY contract repo.
#
# Format: `key = value` globals, then 5 whitespace-separated fields per repo:
#
#   <repo> <min_citations> <max_cross> <max_in_local_range> <max_orphan>
#
# Re-pin DELIBERATELY, in the commit that changes the measured value, with the
# reason in the commit message. A pin that drifts behind reality is a pin
# nobody trusts.
#
# ── the ceilings are a RATCHET, not a wall ───────────────────────────────────
# Unlike trap_sentinel_drift_floors.txt (whose classes are 0 everywhere and
# whose ceilings are therefore a wall), this file was landed with 291 CROSS
# rows standing across 18 repos this session did not own, because per Issue

# issues, not 291 prose edits from here. Each ceiling is pinned at its MEASURED
# count: a NEW unqualified citation reds immediately, and the standing backlog
# is visible in the pins rather than silently tolerated. Lower a ceiling in the
# commit that qualifies a citation.
#
# The backlog was then worked off by the owning repos and the campaign is
# COMPLETE (2026-09-12): **0 CROSS rows across all 19 repos.** The last
# three rows were resolved by archaeology, not by the author lookup the
# file previously said they needed: riir-clippy's two `Issue 665` rows are

# mmorpg-remake's 16 rows were repaired 09:18 (92dff5ca) but the ratchet
# commit never landed — paid here. A ceiling of 0 everywhere makes this
# file a WALL again, all 19 repos.
#
# ⛔ Do NOT read a ceiling as a finding count, and do not read ONE error rate
# over it. Two populations, two rates, never blended (a SAMPLE rate does not
# transfer to rows it never sampled): the pre-752 corpus of 254 carries
# 7/43 = 16% from a stratified manual read across 13 repos (Issue 751 T1); the
# 45 rows recovered by owner-consistency carry 0/45 from a full CENSUS (Issue
# 752). The predecessor figure, 308, was quoted with NO error rate and was ~50%
# contaminated in its first four rows. A count without its error rate is not a
# measurement.
#
# ⛔ A ceiling that FALLS is ambiguous between a repair and a blinded
# classifier. These ten rose in 2026-09-12's re-pin because the qualification
# rule stopped accepting a repo name that does not OWN the number (Issue 752) —
# the instrument got sharper, the prose did not get worse.
#
# ⛔ The corpus MOVES. Five-plus agent sessions edit these documents
# concurrently; riir-mmorpg-examples' HISTORY.md gained 46 lines between two
# runs an hour apart during T1. An exact-ratchet ceiling WILL red on honest new
# prose — that is the design (qualify the citation, or re-pin in that commit),
# and it is why the FLOORS below are slack rather than ratcheted.
#
# ── the two FLOORS ───────────────────────────────────────────────────────────
# max_cross = 0 (or = N) is green over whatever the instrument can SEE.
#
#   min_citations  the per-repo citation walk. A regex regression (a Python \s
#                  handed to an ERE, the classic) takes this to 0 and every
#                  ceiling passes, indistinguishable from clean prose. Pinned
#                  at ~60% of measured: SLACK against churn (removing a
#                  resolved-issue narrative per the noise-reduction rule
#                  legitimately shrinks a repo's count), TIGHT against
#                  blindness (a walk regression drops it to zero, not by 40%).
#                  It is 0 for the three repos with no citations at all —
#                  which is exactly why it cannot be the only floor.
#
#   min_repos      the DERIVED contract-repo set (BOUNDARY.md + .git dir).
#                  Every class below is decided against it: a population that
#                  collapses makes every citation read as local-or-orphan and
#                  the CROSS ceiling passes vacuously. 19 at landing.
#
# min_repos is NOT free: it must equal issue_citation_floors.txt's `min_repos`,
# and the sweep ASSERTS that rather than trusting it — same quantity, two
# files (the trap_sentinel_drift_sweep vs trap_sentinel_gate.POPULATION_FLOOR
# precedent). The `documents` list is deliberately NOT restated here: it is
# read straight out of the gate's pins, because a quantity with one home
# cannot drift.
#
# ── no ceiling on AMBIGUOUS, deliberately ────────────────────────────────────
# 908 cited numbers exist BOTH locally and in a sibling. The referent is
# undecidable from the number and the sweep is green over every one of them by
# construction. A ceiling would red whenever somebody writes a perfectly
# CORRECT citation to a new local number a sibling also happens to have — a
# nuisance red for a right action, and a gate that reds on right actions gets
# bypassed (staged_set_audit.py's rationale, one axis over). It is PRINTED
# every run instead, so a green is never read as a green over everything.
