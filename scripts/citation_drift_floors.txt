# ── the two FLOORS ───────────────────────────────────────────────────────────

#                  blindness (a walk regression drops it to zero, not by 40%).
#                  It is 0 for the three repos with no citations at all —
#                  which is exactly why it cannot be the only floor.
#
#   min_repos      the DERIVED contract-repo set (BOUNDARY.md + .git dir).
#                  Every class below is decided against it: a population that
#                  collapses makes every citation read as local-or-orphan and
#                  the CROSS ceiling passes vacuously. 19 at landing.
#
# min_repos is NOT free: it must equal issue_citation_floors.txt's `min_repos`,
# and the sweep ASSERTS that rather than trusting it — same quantity, two
# files (the trap_sentinel_drift_sweep vs trap_sentinel_gate.POPULATION_FLOOR
# precedent). The `documents` list is deliberately NOT restated here: it is
# read straight out of the gate's pins, because a quantity with one home
# cannot drift.
#
# ── no ceiling on AMBIGUOUS, deliberately ────────────────────────────────────
# 908 cited numbers exist BOTH locally and in a sibling. The referent is

# bypassed (staged_set_audit.py's rationale, one axis over). It is PRINTED
# every run instead, so a green is never read as a green over everything.
