## Goal

Ship a deterministic, modelless low-slice-rank tensor decomposition for 3rd-order tensors X[n, t, k] (entity × time × episode): three single-class truncated-SVD factorizations (Eckart–Young global optima), a closed-form covariability classifier (3 spectra over a shared Frobenius denominator + sigmoid routing), a joint deterministic-ALS demixer with SVD init, and invariance canonicalization (SVD orthogonalize + variance ordering + sign/tie rules). The delta vs the paper's fitter: **deterministic pure-function contract** (same input bytes → bit-identical factors on the same triple/codegen; BLAKE3-replayable) and zero-hyperparameter block updates (contraction + scalar divide — no LR/schedule/masking curriculum). Fitting novelty is NOT claimed (ALS lineage: Carroll & Chang 1970, Harshman 1970, Orth-ALS NeurIPS 2017 arXiv:1703.01804 — cited in module docs).

GOAT gate: G1 synthetic class recovery + invariance fixtures + monotone loss; G2 ≥ truncated-SVD-per-unfolding at equal budget; G3 suites green; G4 alloc-free + determinism repeat-pin.

## Phase 1 — Core module (feature `slice_tca`)

### Tasks

- [x] **T1.1** `mod.rs`: `SliceDecomposition { R: (R_n, R_t, R_k), loadings, slices }` fixed-layout, const-generic bounded sizes; reconstruction `reconstruct_into(&self, x_hat: &mut Tensor3)` zero-alloc (rank-1 GER accumulation, chunk-8 fixed order). — `types.rs`: fixed `MAX_COMPONENTS=24` arrays for class/weight/offset bookkeeping (Vec payload for variable dims — full const-generic shape instantiation is incompatible with runtime rank selection from T2.1); GER via `simd_fused_scale_acc` per class with fixed loop order; `frob_sq` chunk-8 fixed-order accumulation.
- [x] **T1.2** Single-class path: `fit_single_class(X, axis, R)` = truncated SVD of the unfolding via existing `thin_svd_into`/power-iteration (spectral substrate); document Eckart–Young optimality (paper's own reduction: single-slice-type ≡ unfolding matrix factorization). — `svd.rs`: consumed `thin_svd_into` on the small-side Gram `G_σ = X_(σ)X_(σ)ᵀ` (U from the Gram SVD; right side recovered by one contraction `Y_r = u_rᵀ X_(σ)`); `σ_r = ‖Y_r‖` is an exact identity so the Gram and HOSVD basis paths trim identically; condition-squaring caveat documented in `svd.rs` + Bench 714.
- [x] **T1.3** Classifier: `covariability_shares(X, R) -> [f32; 3]` — top-R singular spectra of the three unfoldings over shared `‖X‖²_F`; `route(share, θ, α) = sigmoid(α·(EVR−θ))` (sigmoid, never softmax — classes not mutually exclusive). — `svd.rs`; consumed `crate::sigmoid` (always-on root primitive).
- [x] **T1.4** Joint ALS: block update per component = one tensor contraction + scalar divide (ε-floored); components born with their class (class fixed at construction — between-class invariance cannot drift under ALS); fixed iteration count, fixed order; SVD-init greedy by EVR. Consume `linalg/tucker.rs` HOSVD as the joint initializer (gives Tucker its first consumer) or record in this plan why deflation-init won. — `als.rs`: loading-axis-only block updates (slice matrices FROZEN at SVD birth ⇒ class cannot drift, literally); HOSVD consumed as the joint initializer via `tucker_decompose_into` for shapes inside `TuckerConfig`'s `SVD_MAX_RANK=16` bound (first in-tree Tucker consumer; test-pinned weight-parity vs the Gram path) with automatic Gram-SVD fallback for large shapes — recorded reason: the Tucker bound rejects e.g. `[64,128,32]` (mode-1 min-dim 128 > 16). Not deflation-init — no sequential subtraction anywhere.
- [x] **T1.5** Canonicalization (paper L3/L2): SVD orthogonalization + variance-desc stable sort `(σ desc, lexicographic)` + sign rule (largest-|·| entry positive, first-index tie-break); between-class rank-1 reallocation = closed-form projection in the generic case, documented-degenerate otherwise. — `types.rs::canonicalize` (unit-slice normalization + sign rule + bit-pattern-lexicographic variance-desc sort; bases are born orthonormal from SVD so the orthogonalization half is inherited at birth and ALS cannot un-orthogonalize slices it never moves); `als.rs::reallocate_class` (rank-1 split of the slice matrix ⇒ exact for rank-1 slices, returns the residual ratio for generic ones — degenerate case test-pinned).
- [x] **T1.6** Determinism contract test: BLAKE3(hash(factors)) identical across N=16 calls + a rebuild; hazards pinned (no HashMap, no rayon in fit path, no runtime-adaptive ε, fixed-order accumulation). — `tests.rs::determinism_blake3_across_calls_and_rebuild` (16 calls, fresh scratch every 4th + drop-and-rebuild) + the contract section in `mod.rs` docs.
- [x] **T1.7** Property tests: ALS loss monotone non-increasing; reconstruction round-trip; planted `u⊗v⊗z` passed between classes → canonical output unchanged. — `als_loss_monotone_non_increasing` (init loss recorded as element 0 so the assertion is live), `full_pipeline_reconstruction_round_trip`, `class_pass_canonical_output_unchanged` (weights identical; recon agreement 1.19e-7; only the class label differs).
