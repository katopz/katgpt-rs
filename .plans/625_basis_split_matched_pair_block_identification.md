## Goal

A certified block split over (frozen embedding accessor, matched pairs): variant basis (top eigenspace of the whitened pair-difference second moment), invariant projector (complement), a refuse-loud identifiability verdict, and a held-out `pair_leakage` residual. Composes existing substrate; forks nothing.

## Non-goals

- No encoder training (that is the riir-train plan, gated on this primitive).
- No consumer wiring — each consumer repo carries its own issue; this plan ships the primitive + bench + gates only.
- **No new eigensolver.** `katgpt-core::linalg::symmetric_eig` (f64, deterministic, Householder+QL, documented d ≥ 256) and `karc::jacobi_eigen` (small d) exist; `katgpt-spectral` already carries three private Jacobi copies — a fifth is a DRY violation.
- No new cross-crate dependency: self-contained in `katgpt-core`.

## Phase 1 — core primitive (`crates/katgpt-core/src/basis_split.rs`) — **LANDED 2026-10-12**

- [x] T1.1 Whitening-default geometry — **DONE**: `Whitening::TotalCovariance(&Σ)` (split() builds the ZCA whitener `W = Σ^{-1/2}` via `build_zca_whitener` and applies the similarity transform `M' = W M Wᵀ` itself — d³ calibration-time work) or `Whitening::Whitener(&W)` (the streaming path — the moment was pre-whitened at accumulate time through `PairDifferenceMoment::accumulate_whitened`); neither → `Verdict::Unwhitened` (refuse-loud). Generalized-eigenproblem equivalence documented in the module header. ⚠ Design fix caught by the quiet-axis test: the first draft built W under TotalCovariance but never applied it (Σ=I fixtures hid it) — the transform is load-bearing.
- [x] T1.2 `PairDifferenceMoment` — **DONE**: `accumulate` (symmetric rank-1, exact-zero rows skipped, non-finite refuses BEFORE mutation), `accumulate_whitened` (scratch receives `Δ Wᵀ`, zero-alloc), `finish` (÷N in place). f64 throughout; all buffers caller-owned; deterministic order. Solver routing: d ≤ 16 `karc::jacobi_eigen` (tol 1e-14, 100 sweeps), else `linalg::symmetric_eig` — parity pinned by test at d=12 (jacobi vs fresh QL, ≤1e-9).
- [x] T1.3 Rank gate (`SufficientVariation`) — **DONE**: `check_rank_gate(eigvals_desc, k: Option<usize>, tau_gap)` — supplied-k form checks `λ_k / λ_{k+1} ≥ τ_gap`; k=None selects at the largest gap and reports `k_from_gap: true`; the gap ratio rides EVERY verdict (report + `Unidentified` reason). NaN (0/0 rank-exhausted moment) refuses; **+inf PASSES** (an exact-zero block below the boundary is the STRONGEST gap evidence — caught by the planted test: the first draft refused inf). Participation ratio delegates to the EXISTING `subspace_phase_gate::participation_ratio` (f32, report-only — a DRY find; the f64 duplicate was removed). Below the gate ⇒ `Verdict::Unidentified` (refuse-loud).
- [x] T1.4 Split — **DONE**: `split()` emits the variant basis (`k×d` rows = top-k eigenvector columns, sorted descending by an in-place zero-alloc heapsort with lockstep column permutation — the sort's first draft was ASCENDING, a classic max-heap+extract-to-end bug caught by the planted test), columns normalized orthonormal; `project_invariant_into(&basis, k, d, x, bx_scratch, out)` = `x − Bᵀ(B x)` (one d×d-matvec class, ns-class at d=64).
